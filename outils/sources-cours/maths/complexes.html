Définition et opérations

diapos 4 à 14 · 35 min
L'idée. x² − 2x + 5 = 0 n'a pas de solution réelle (Δ = −16). On ajoute un nombre i tel que i² = −1, et toutes les équations du second degré ont des solutions : ici 1 + 2i et 1 − 2i.
z = a + ib avec a, b ∈ ℝ et i² = −1 a = Re(z) : partie réelle ; b = Im(z) : partie imaginaire z = z' ⇔ Re(z) = Re(z') et Im(z) = Im(z') Conjugué : z* = z̄ = a − ib
Coquille du cours (diapo 6). La définition précise « b est non nul » : il faut l'enlever. a et b sont deux réels quelconques ; si b = 0, z est un réel (qui est aussi un complexe), et si a = 0, z est un imaginaire pur. Zéro est à la fois réel et imaginaire pur.
Propriétés du conjugué : conj(z̄) = z Re z = (z + z̄)/2 Im z = (z − z̄)/(2i) z ∈ ℝ ⇔ Im z = 0 ⇔ z = z̄ z ∈ iℝ ⇔ Re z = 0 ⇔ z = −z̄ conj(z + z') = z̄ + z̄' conj(z z') = z̄ z̄' conj(z'/z) = z̄'/z̄ z z̄ = (Re z)² + (Im z)² = a² + b²
Addition : (a₁ + ib₁) + (a₂ + ib₂) = (a₁ + a₂) + i(b₁ + b₂) Multiplication : (a₁ + ib₁)(a₂ + ib₂) = (a₁a₂ − b₁b₂) + i(a₁b₂ + b₁a₂) Division : on multiplie en haut et en bas par le conjugué du dénominateur z₁/z₂ = [(a₁a₂ + b₁b₂) + i(b₁a₂ − a₁b₂)] / (a₂² + b₂²)
Exemple corrigé · les calculs des diapos 11 à 14
Voir la correction
(3 + 4i) + (1 − 2i) = 4 + 2i (5 + 3i) − (2 + 7i) = 3 − 4i (2 + 3i)(1 − 4i) = 2 − 8i + 3i − 12i² = 2 + 12 − 5i = 14 − 5i (2 + 3i)/(5 − 2i) = (2 + 3i)(5 + 2i) / (25 + 4) = (10 + 4i + 15i − 6)/29 = (4 + 19i)/29
Piège. Dans un produit, i² devient −1 : c'est ce qui change le signe de b₁b₂. Dans une division, on ne divise jamais « partie par partie ».

(1 + i)² vaut :

(1 + i)² = 1 + 2i + i² = 1 + 2i − 1 = 2i.

Plan complexe, module, argument, forme trigonométrique

diapos 15 à 22 · 35 min
L'idée. z = a + ib est le point A(a, b) du plan (plan d'Argand). Sa distance à O est le module, l'angle avec l'axe des réels est l'argument : on peut décrire z par ces deux nombres au lieu de a et b.
Module : |z| = √(a² + b²) (Pythagore) Argument : θ = arg(z), en radians, tan θ = b/a Forme trigonométrique : z = r(cos θ + i sin θ) avec r = |z|, θ = arg(z) a = r cos θ ; b = r sin θ
PointQuadrantArgument (α = arctan |b/a|)
a > 0, b > 0Iθ = α
a < 0, b > 0IIθ = π − α
a < 0, b < 0IIIθ = α − π
a > 0, b < 0IVθ = −α
Piège : arctan(b/a) ne suffit pas. arctan donne un angle entre −π/2 et π/2. Pour −3 + 4i, arctan(4/(−3)) = −0,93 rad est faux : le point est dans le quadrant II, θ = π − arctan(4/3).
Produit : |z₁z₂| = |z₁| |z₂| et arg(z₁z₂) = arg z₁ + arg z₂

Voir la correction
Point A(3 ; 4) : |z| = √(9 + 16) = 5, arg = arctan(4/3) = 53,13° z = 1 + i : r = √2, θ = π/4 → z = √2 (cos π/4 + i sin π/4) z = −1 + √3 i : r = 2, quadrant II, α = arctan √3 = π/3, θ = π − π/3 = 2π/3 z = −3 + 4i : r = 5, θ = π − arctan(4/3) ≈ 2,214 rad (126,9°) z₁ = 6(cos π/3 + i sin π/3), z₂ = 4(cos π/4 + i sin π/4) : z₁z₂ = 24 (cos 7π/12 + i sin 7π/12)

Formule d'Euler : e^(iθ) = cos θ + i sin θ Forme exponentielle : z = r e^(iθ) |e^(iθ)| = 1 conj(e^(iθ)) = e^(−iθ) = 1/e^(iθ) e^(i(θ+θ')) = e^(iθ) e^(iθ') e^(iθ) = 1 ⇔ θ = 2kπ, k ∈ ℤ identité d'Euler : e^(iπ) + 1 = 0
r₁e^(iθ) × r₂e^(iθ') = (r₁r₂) e^(i(θ+θ')) r₂e^(iθ) / r₁e^(iθ') = (r₂/r₁) e^(i(θ−θ')) zⁿ = (re^(iθ))ⁿ = rⁿ e^(inθ) De Moivre : (cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ) Exponentielle complexe : e^z = e^(Re z) e^(i Im z)

Racines carrées et racines n-ièmes

diapos 36 à 40 · 40 min
L'idée. Tout complexe non nul a exactement n racines n-ièmes, régulièrement réparties sur un cercle (écart 2π/n). Pour une racine carrée en forme algébrique, on identifie parties réelles, imaginaires et modules.
Racine carrée Z = A + iB de z = a + ib (Z² = z) : A² + B² = √(a² + b²) (|Z|² = |z|) A² − B² = a (Re Z² = Re z) AB du signe de b (Im Z² = 2AB = b)
Racines n-ièmes de l'unité (zⁿ = 1) : z_k = e^(i2kπ/n), k = 0, 1, …, n − 1 Racines n-ièmes de ω = re^(iθ) : z_k = r^(1/n) e^(i(θ + 2kπ)/n), k = 0, …, n − 1

Équations du second degré et polynômes

diapos 41 à 47 · 40 min
L'idée. Dans ℂ, le discriminant a toujours des racines carrées : une équation du second degré a toujours des solutions. Pour un degré plus grand, on factorise grâce à une racine connue (division euclidienne ou tableau de Hörner).
az² + bz + c = 0 (a, b, c ∈ ℂ, a ≠ 0) ; Δ = b² − 4ac Δ = 0 : racine double z₀ = −b/(2a) Δ ≠ 0 : δ une racine carrée de Δ → z₁ = (−b − δ)/(2a) ; z₂ = (−b + δ)/(2a)
Coquille du cours (diapo 41). Les deux racines y sont écrites « z₁ = −b−δ / 2a et z₂ = −b−δ / 2a » : la seconde est (−b + δ)/(2a), et il faut des parenthèses autour du numérateur.
Division euclidienne : A = BQ + R avec deg R < deg B (Q et R uniques) Hörner (racine r connue) : on recopie le 1er coefficient, puis à chaque colonne (nombre du bas à gauche) × r + coefficient du haut ; la dernière case doit valoir 0 la ligne du bas donne les coefficients de P(x)/(x − r)
Exemple corrigé · division euclidienne (diapo 43)

Diviser 2X⁴ − X³ − 2X² + 3X − 1 par X² − X + 1.

Voir la correction
Q = 2X² + X − 3 ; R = −X + 2 Vérification : (X² − X + 1)(2X² + X − 3) − X + 2 = 2X⁴ − X³ − 2X² + 3X − 1 ✓
Exemple corrigé · Hörner (diapos 46 et 47)

P(x) = x⁴ − 2x³ − 7x² + 8x + 12, racine évidente r = 3.

Voir la correction
coefficients : 1 −2 −7 8 12 × 3 : 3 3 −12 −12 ligne du bas : 1 1 −4 −4 0 ✓ (r = 3 est racine) P(x) = (x − 3)(x³ + x² − 4x − 4) = (x − 3)(x + 1)(x² − 4) = (x − 3)(x + 1)(x − 2)(x + 2) racines : 3, −1, 2, −2

Applications aux circuits : phaseurs et impédances

diapos 48 à 52 et fiche « Application 2 » · 35 min
L'idée. Une tension sinusoïdale Vm cos(ωt + φ) est la partie réelle de Vmeiφeiωt. On garde seulement Vmeiφ, le phaseur, et les équations du circuit deviennent algébriques. En physique, l'unité imaginaire se note j.
v(t) = V_m cos(ωt + φ) → phaseur Ṽ = V_m e^(jφ) = V_m ∠φ = V_m cos φ + j V_m sin φ Loi d'Ohm : Ṽ = Z Ĩ (convention récepteur) Z_R = R Z_L = jLω (tension en avance de π/2) Z_C = 1/(jCω) = −j/(Cω) (courant en avance de π/2) Série : Z = Σ Z_k Parallèle : 1/Z = Σ 1/Z_k (admittance Y = 1/Z)
Exemple corrigé · diapo 52

R = 10 Ω et L = 100 mH en série, v(t) = 50 cos(1000t). Impédance et courant i(t) ?

Voir la correction
Z = R + jLω = 10 + j × 0,1 × 1000 = 10 + 100j |Z| = √(100 + 10 000) = 100,5 Ω ; arg Z = arctan(10) = 1,471 rad (84,3°) Ĩ = Ṽ / Z = 50∠0 / 100,5∠1,471 = 0,4975∠(−1,471) i(t) = 0,4975 cos(1000t − 1,471) (A)

Voir la correction
