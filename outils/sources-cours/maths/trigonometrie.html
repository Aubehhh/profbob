Cercle trigonométrique et fonctions circulaires

diapos 5 à 9 · 30 min
L'idée. Sur le cercle de centre O et de rayon 1, le point d'angle θ a pour coordonnées (cos θ, sin θ). La tangente est la pente de la droite qui relie O à ce point.
sin θ = opposé/hypoténuse cos θ = adjacent/hypoténuse tan θ = opposé/adjacent csc θ = 1/sin θ sec θ = 1/cos θ cot θ = 1/tan θ Cercle trigonométrique : x² + y² = 1 x ≡ y [2π] ⇔ ∃k ∈ ℤ, x = y + 2kπ
cos' = −sin ; sin' = cos ; |sin x| ≤ |x| tan x = sin x / cos x pour x ≠ π/2 + kπ ; tan' x = 1 + tan² x = 1/cos² x
Exemple corrigé · diapo 7
Voir la correction
sin(π/4) = √2/2 −19π/6 = −19π/6 + 4π = 5π/6 [2π] → sin(−19π/6) = sin(5π/6) = 1/2
Piège. Pour un angle « bizarre », on enlève ou on ajoute des tours complets (2π) jusqu'à tomber dans ]−π, π] ou [0, 2π[, puis on lit la valeur sur le cercle.

Identités et formules de trigonométrie

diapos 10 à 17 · 45 min
L'idée. Quelques formules suffisent pour calculer les valeurs exactes d'angles non remarquables (15°, 22,5°, 75°…) et pour transformer des produits en sommes.
Pythagore : sin² θ + cos² θ = 1 ; 1 + tan² θ = sec² θ ; 1 + cot² θ = csc² θ Sommes et différences : sin(A ± B) = sin A cos B ± cos A sin B cos(A ± B) = cos A cos B ∓ sin A sin B tan(A ± B) = (tan A ± tan B) / (1 ∓ tan A tan B) Angles doubles : sin 2θ = 2 sin θ cos θ ; cos 2θ = cos² θ − sin² θ ; tan 2θ = 2 tan θ / (1 − tan² θ) Angles moitiés : sin(θ/2) = ±√((1 − cos θ)/2) ; cos(θ/2) = ±√((1 + cos θ)/2) Produits : 2 cos a cos b = cos(a + b) + cos(a − b) 2 sin a cos b = sin(a + b) + sin(a − b) 2 sin a sin b = cos(a − b) − cos(a + b)
Exemple corrigé · diapos 10 à 15
Voir la correction
sin θ / (1 + cos θ) = 2 sin(θ/2) cos(θ/2) / (2 cos²(θ/2)) = tan(θ/2) sin 75° = sin(45° + 30°) = (√2/2)(√3/2) + (√2/2)(1/2) = (√6 + √2)/4 ≈ 0,966 sin 22,5° = √((1 − cos 45°)/2) = √(2 − √2) / 2 ≈ 0,383 (positif : angle du 1er quadrant) (on retrouve cos 2θ = 1 − 2 sin² θ avec θ = 22,5°) sin(π/12) = sin(π/3 − π/4) = (√3/2)(√2/2) − (1/2)(√2/2) = (√6 − √2)/4 ≈ 0,259
Exemple corrigé · diapos 16 et 17

Onde y(x, t) = A sin(kx − ωt) ; vaisseau à 10 000 km/h pendant 2 h, à 30° de la verticale.

Voir la correction
∂y/∂x = Ak cos(kx − ωt) ; ∂y/∂t = −Aω cos(kx − ωt) (∂y/∂t) / (∂y/∂x) = −ω/k distance parcourue = 10 000 × 2 = 20 000 km composante verticale = 20 000 × cos 30° ≈ 17 320 km

Le rapport vaut −ω/k ; la vitesse de l'onde, elle, est v = ω/k (positive, l'onde avance vers les x croissants). La diapo écrit « v = −ω/k » : retiens que le rapport des dérivées vaut −v.

Équations trigonométriques

diapos 28 à 33 · 45 min
L'idée. Une équation trigonométrique a en général une infinité de solutions : on donne la solution générale « + 2kπ » (ou « + kπ »), puis on ne garde que celles de l'intervalle demandé.
sin x = sin a ⇔ x = a + 2kπ ou x = π − a + 2kπ cos x = cos a ⇔ x = a + 2kπ ou x = −a + 2kπ tan x = tan a ⇔ x = a + kπ
Piège. Ne pas confondre [0, 2π] et [−π, π], et ne pas oublier la seconde famille de solutions (π − a pour le sinus, −a pour le cosinus). Sur un intervalle, on écrit S = {…}.
Exemple corrigé · diapos 29 et 30
Voir la correction
sin x = 1/2 → x = π/6 + 2kπ ou x = 5π/6 + 2kπ cos 2x = 1/2 → 2x = ±π/3 + 2kπ → x = ±π/6 + kπ sin 3x = −√2/2 → 3x = −π/4 + 2kπ ou 5π/4 + 2kπ → x = −π/12 + 2kπ/3 ou x = 5π/12 + 2kπ/3 sin(2x − π/3) = cos(π/2 + 3x) = −sin 3x = sin(−3x) → 2x − π/3 = −3x + 2kπ ⇒ x = π/15 + 2kπ/5 ou 2x − π/3 = π + 3x + 2kπ ⇒ x = −4π/3 − 2kπ

Voir la correction

Puissances, exponentielle et logarithmes

diapos 35 à 40 · 30 min
L'idée. L'exponentielle transforme une somme en produit, le logarithme fait l'inverse. Le logarithme de base b est la réciproque de bˣ.
(xy)ⁿ = xⁿyⁿ ; x^(m+n) = x^m xⁿ ; (x^m)ⁿ = x^(mn) ; racine n-ième : x^(1/n) eˣ = lim (n→∞) (1 + x/n)ⁿ ; domaine ℝ, image ]0, +∞[ ; (eˣ)' = eˣ ; ∫ eˣ dx = eˣ + C lim (x→−∞) eˣ = 0 ; lim (x→+∞) eˣ = +∞ log_b(x) défini pour x > 0 : log_b(1) = 0 ; log_b(b) = 1 log_b(xy) = log_b x + log_b y ; log_b(xⁿ) = n log_b x (log_b x)' = 1/(x ln b) ; ∫ log_b x dx = (x ln x − x)/ln b + C ln = log_e : domaine ]0, +∞[, image ℝ ; (ln x)' = 1/x ; ∫ ln x dx = x ln x − x + C ; lim (x→0⁺) ln x = −∞
Coquilles du cours (diapos 37 et 39). L'image de l'exponentielle et le domaine de ln sont écrits « [0, ∞[ » : c'est ]0, +∞[ (0 est exclu : eˣ ne s'annule jamais et ln 0 n'existe pas). « Strictement continue » ne veut rien dire : la fonction est continue et strictement croissante.
Exemple corrigé · diapo 40

Dérivée de f(x) = log₂(x³ + x).

Voir la correction
f(x) = ln(x³ + x) / ln 2 → f'(x) = (3x² + 1) / ((x³ + x) ln 2) (x > 0)

Fonctions hyperboliques

diapos 41 à 49 · 40 min
L'idée. Les fonctions hyperboliques s'écrivent avec des exponentielles. Le point (cosh t, sinh t) décrit la moitié droite de l'hyperbole x² − y² = 1, comme (cos t, sin t) décrit le cercle. La chaînette (un câble suspendu) a la forme de cosh.
sinh x = (eˣ − e⁻ˣ)/2 cosh x = (eˣ + e⁻ˣ)/2 tanh x = sinh x / cosh x coth x = cosh x / sinh x sech x = 1/cosh x csch x = 1/sinh x cosh² x − sinh² x = 1 sinh' = cosh ; cosh' = sinh ; tanh' = sech² ; coth' = −csch² ; sech' = −sech tanh ; csch' = −csch coth ∫ sinh = cosh + C ; ∫ cosh = sinh + C ; ∫ tanh = ln(cosh x) + C ; ∫ sech² = tanh + C sinh 2x = 2 sinh x cosh x ; cosh 2x = cosh² x + sinh² x = 2 cosh² x − 1 = 1 + 2 sinh² x tanh 2x = 2 tanh x / (1 + tanh² x)
Piège : les signes changent par rapport au cercle. cosh' = +sinh (et non −), et cosh² − sinh² = 1 (et non +).

Voir la correction

Exercices du chapitre

applications des diapos

Valeurs exactes sections 1 et 2

Méthode

Décompose l'angle en somme ou différence d'angles remarquables (75° = 45° + 30°, 15° = 45° − 30°), ou en moitié d'un angle remarquable (22,5° = 45°/2), puis applique la formule adaptée.

Domaines des fonctions réciproques section 3

Méthode

Écris la condition sur ce qui est « à l'intérieur » (entre −1 et 1 pour arcsin et arccos, |·| ≥ 1 pour arcsec et arccsc), résous en x, puis cherche les valeurs atteintes par l'intérieur pour obtenir l'image.

Équations dans [0, 2π] section 4

Méthode

Factorise si possible (sin 2x = 2 sin x cos x), ou pose X = cot x et résous une équation du second degré, puis liste toutes les solutions de l'intervalle, en vérifiant qu'aucune n'en sort.
