1

Le CSS et son intégration

diapos 4 à 6 · 20 min
L'idée. Le HTML dit ce que c'est (un titre, un paragraphe, un bloc) ; le CSS (Cascading Style Sheets) dit à quoi ça ressemble (couleurs, tailles, positions). Le navigateur applique le CSS côté client.
Le débogueur du navigateur (F12, ou F8 selon le navigateur) montre la structure HTML, le CSS appliqué à chaque élément et la console d'erreurs JavaScript. C'est l'outil n°1 pour comprendre pourquoi un style ne s'applique pas.

Cumul des précisions. En enchaînant les sélecteurs avec des espaces, on vise des éléments placés à l'intérieur d'autres : .class td {} vise les cellules contenues dans un élément de cette classe ; #id .class span {} vise les span dans un élément de classe « class », lui-même dans l'élément #id.

[class^="toto"] {}      /* la classe commence par « toto » */
[class$="test"] {}      /* la classe finit par « test » */
[class*="te"]   {}      /* la classe contient « te » */
input[type="text"] {}   /* les input dont l'attribut type vaut text */
Piège. Un id doit être unique dans la page ; une class peut être donnée à autant d'éléments qu'on veut. Dans le CSS, on n'oublie pas le # ou le . : test { } viserait des balises <test>, qui n'existent pas.

Unités et propriétés principales

diapos 16 à 22 · 40 min
L'idée. Il existe des centaines de propriétés, mais une poignée suffit pour l'essentiel : fond, texte, bordures, espacements, taille et position.
FamillePropriétés (exemples de valeurs)
Tailles% (largeurs, marges) ; px (petites marges) ; em, pt (polices, arrondis)
Fondbackground-color ; background-image: url("…") ; background-position: left/center/right top/center/bottom ; background-repeat: repeat / repeat-x / repeat-y / no-repeat ; background (raccourci)

Dégradéslinear-gradient(couleur, couleur) ; linear-gradient(angle ou direction, couleur, couleur) ; repeating-linear-gradient(…)
Couleurs : mots-clés blue, white, yellow… hexadécimal #RRGGBB (#00FF32 : rouge 00, vert FF, bleu 32) hexadécimal court #RGB (#F80 = #FF8800) rgb(0-255, 0-255, 0-255) et rgba(…, opacité de 0 à 1) autres : hsl, hsla…
Hexadécimal → décimal : chaque paire de chiffres est un nombre de 0 à 255 chiffres 0-9 puis A=10, B=11, C=12, D=13, E=14, F=15 « 3C » = 3 × 16 + 12 = 60 ; « FF » = 15 × 16 + 15 = 255
Coquilles du cours (diapos 16 à 21).
  • em n'est pas un « pouce » : 1 em = la taille de la police de l'élément (pour les pouces, l'unité CSS est in).
  • L'italique ne se règle pas avec font-weight (épaisseur : normal, bold, 100 à 900), mais avec font-style: italic.
  • L'épaisseur de bordure s'appelle border-width, pas border-size.
  • float n'accepte que left, right ou none (pas top ni bottom).
  • rgb() prend des valeurs de 0 à 255 ou des pourcentages, pas de 0 à 1 ; seule l'opacité de rgba() va de 0 à 1.

Responsive design et media queries

diapos 24 à 29 · 25 min
L'idée. Une même page doit s'adapter à un ordinateur, un téléphone, une tablette. Une media query applique des règles CSS seulement quand une condition sur l'écran est vraie.
@media type and (contrainte) { règles CSS } type : screen, print, all… contraintes : max-width, min-width, combinées avec and
#test {
  width: 95%;
}

@media screen and (max-width: 640px) {
  #test {
    width: 80%;
  }
}

Sur un écran de 640 px de large ou moins, #test fait 80 % de la largeur ; au-delà, la règle générale s'applique (95 %). La règle de la media query est écrite après, donc elle l'emporte quand sa condition est vraie.

Piège. max-width: 640px veut dire « jusqu'à 640 px inclus » ; min-width: 640px veut dire « à partir de 640 px ». Et parmi les types listés en diapo 27 (handheld, aural, tty, tv, projection, embossed), seuls screen, print et all sont encore utilisés : les autres sont abandonnés.

Avec l'exemple ci-dessus, sur un téléphone de 390 px de large, #test fait :

390 ≤ 640 : la condition max-width: 640px est vraie, la règle à 80 % s'applique.
