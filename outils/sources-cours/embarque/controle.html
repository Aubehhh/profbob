1

Créer une fonction

chapitre 2, diapos 3 à 8 · 35 min
L'idée. Une fonction regroupe des instructions sous un nom, pour les réutiliser avec des paramètres différents au lieu de recopier le code.
void blink(int Number, int time) {   // type, nom, paramètres
  digitalWrite(Number, HIGH);
  delay(time);
  digitalWrite(Number, LOW);
  delay(time);
}

void loop() {
  blink(8, 1000);    // LED du port 8 : 1 s
  blink(9, 2000);    // LED du port 9 : 2 s
}
1) type de retour : void (ne renvoie rien), int (un entier), boolean (vrai/faux) 2) nom de la fonction 3) paramètres : chacun avec un type et un nom, autant qu'on veut 4) le contenu, entre accolades { } Un programme a au moins deux fonctions : setup() et loop()
Piège. Une fonction déclarée int doit se terminer par return suivi d'une valeur. Si elle ne renvoie rien (allumer une LED, par exemple), on la déclare void.
Exemple corrigé · quiz des diapos 3 et 4

Le programme int Ledpin = 9; pinMode(Ledpin, OUTPUT); digitalWrite(Ledpin, HIGH); delay(2000); digitalWrite(Ledpin, LOW); delay(2000); ne compile pas. Que manque-t-il, et que fait-il une fois corrigé ?

Voir la correction

Il manque setup() (pour le pinMode) et loop() (pour le clignotement). Corrigé, il fait clignoter la LED du port 9 : 2 s allumée, 2 s éteinte, soit une période de 4 s.

2

Lire un bouton : pull-down et pull-up

diapos 9 à 11 · 25 min
L'idée. Un bouton se lit avec digitalRead. L'état HIGH ou LOW quand on appuie dépend du câblage, d'où les deux montages pull-down et pull-up.
int pinbutton = 8;
bool value = 0;

void setup() {
  pinMode(pinbutton, INPUT);
  Serial.begin(9600);
}

void loop() {
  value = digitalRead(pinbutton);   // HIGH (1) ou LOW (0)
  Serial.println(value);
  delay(1000);
}
MontageBouton relâchéBouton appuyé
pull-down (résistance vers 0 V)LOW (0 V)HIGH (5 V)
pull-up (résistance vers 5 V)HIGH (5 V)LOW (0 V)
Coquille du cours (diapo 9). Le code affiché écrit deaiy(1000) : c'est delay(1000).
3

if… else et conditions multiples

diapos 12 à 18 · 35 min
L'idée. if teste une condition une seule fois : si elle est vraie, on exécute le bloc ; sinon, le bloc else. Avec && et ||, on combine plusieurs conditions.
A == B égal A != B différent A > B strictement supérieur A >= B supérieur ou égal (et <, <=) && ET : les deux conditions doivent être vraies || OU : il suffit qu'une des deux soit vraie
Coquille du cours (diapos 12, 19 et 21). « Différent de » s'écrit !=, pas =!. Écrit A =! B, le programme met « non B » dans A au lieu de comparer. Et attention : = affecte une valeur, == compare.
int value = 0;

void loop() {
  if (value < 4) {
    Serial.println(value);
    delay(1000);
    value = value + 1;
  } else {
    Serial.println("number too big");
  }
}
// affiche 0, 1, 2, 3, puis « number too big » sans fin
Exemple corrigé · exercices des diapos 14 et 17

Allumer une LED 1 s quand on appuie sur le bouton (montage : le bouton met le port à l'état haut). Puis allumer une LED quand les deux boutons des ports 8 et 9 sont appuyés, et enfin quand l'un des deux l'est.

Voir la correction
int button = 8;
int led = 9;

void setup() {
  pinMode(button, INPUT);
  pinMode(led, OUTPUT);
}

void loop() {
  if (digitalRead(button) == HIGH) {
    digitalWrite(led, HIGH);
    delay(1000);
    digitalWrite(led, LOW);
  }
}

// les deux boutons :      if (digitalRead(button1) == HIGH && digitalRead(button2) == HIGH)
// au moins un bouton :    if (digitalRead(button1) == HIGH || digitalRead(button2) == HIGH)

Pour que la LED s'éteigne quand on relâche, ajoute un else { digitalWrite(led, LOW); }.

4

Les boucles while et for

diapos 19 à 26 · 40 min
L'idée. while répète tant que la condition est vraie ; for répète un nombre de fois connu, avec un compteur. if, while et for peuvent produire le même affichage, mais pas de la même façon.
int variable = 0;
while (variable < 4) {        // tant que la condition est vraie
  Serial.println(variable);
  delay(1000);
  variable = variable + 1;
}

for (int i = 0; i < 4; i = i + 1) {   // départ ; condition ; évolution
  Serial.println(i);
  delay(1000);
}
for (départ ; condition ; évolution) for (int i = a; i < b; i++) s'exécute b − a fois (i va de a à b − 1) i n'existe qu'à l'intérieur de la boucle ; i++ revient à i = i + 1 while (condition) : la condition est testée avant chaque tour ; si elle ne devient jamais fausse, la boucle ne s'arrête jamais
Programme qui compte jusqu'à 3, placé dans loop()Affichage
if… else (la variable est déclarée en dehors de loop)0 1 2 3, puis « too big » à chaque tour
while (variable déclarée en dehors de loop)0 1 2 3 une seule fois, puis plus rien
for (i recréé à chaque entrée dans la boucle)0 1 2 3, puis 0 1 2 3… à chaque tour de loop
Exemple corrigé · exercices de la diapo 24

1) Une fonction qui fait clignoter une LED un nombre de fois donné. 2) Refaire la fonction delay avec un while, en supposant qu'un tour de boucle dure 1 ms.

Voir la correction
void blink_number(int pin, int number) {
  for (int i = 0; i < number; i = i + 1) {
    digitalWrite(pin, HIGH);
    delay(1000);
    digitalWrite(pin, LOW);
    delay(1000);
  }
}
// blink_number(9, 5) : la LED du port 9 clignote 5 fois (10 s en tout)

void delay_while(int time) {
  int value = 0;
  while (value < time) {
    value = value + 1;          // on suppose 1 ms par tour
  }
}
// delay_while(1000) attend environ 1 s

En réalité, un tour de cette boucle dure bien moins d'une milliseconde : c'est pour cela qu'on utilise delay() ou millis(), qui s'appuient sur un timer.

Exercices du chapitre

TD 1 et TD 2

TD 1 · bouton qui inverse l'ordre des LED sections 2 et 3

Méthode

Pour réagir à un appui (et non à un bouton maintenu), on compare l'état actuel à l'état précédent : if (etatActuel == HIGH && etatAncien == LOW) { etat = !etat; }, puis etatAncien = etatActuel;. C'est la détection de front montant.

TD 2 · « Hello » qui fait des allers-retours sur le LCD sections 3 et 4

Méthode

« Hello » fait 5 lettres : sur 16 colonnes, il peut commencer de la colonne 0 à la colonne 11. Une variable sens (+1 ou −1) suffit : à chaque tour, col = col + sens, et on change le signe quand col atteint 0 ou 11.
