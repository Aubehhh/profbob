Continuité

diapos 4 à 6 · 20 min
L'idée. Une fonction est continue en c si on peut tracer sa courbe autour de c sans lever le crayon : quand x se rapproche de c, f(x) se rapproche de f(c).
f continue en c : ∀ε > 0, ∃η > 0, ∀x ∈ D_f, |x − c| < η ⇒ |f(x) − f(c)| < ε c'est-à-dire lim (x→c) f(x) = f(c) continue à gauche : même chose avec c − η < x < c ; à droite : avec c < x < c + η
  • Les fonctions polynômes, rationnelles, circulaires, racines, puissances, logarithmes et exponentielles sont continues sur leur domaine de définition.
  • Sommes, produits et quotients (quand ils sont définis) de fonctions continues sont continus.
Exemple corrigé · fiche d'exercices 2, exercice 1

g(t) = arctan(t)/t. Domaine, et valeur de g(0) qui rend g continue en 0 ?

Voir la correction
D_g = ℝ* (division par t) arctan(t)/t = (arctan t − arctan 0)/(t − 0) → arctan'(0) = 1/(1 + 0²) = 1 On pose g(0) = 1 : g est alors continue en 0 (prolongement par continuité).

Dérivabilité et dérivées usuelles

diapos 7 à 13 · 35 min
L'idée. Le nombre dérivé f'(a) est la pente de la tangente en a : la limite du taux d'accroissement. Dérivable implique continue, mais pas l'inverse (|x| est continue en 0 sans y être dérivable).
f'(a) = lim (h→0) [f(a + h) − f(a)] / h Développement limité d'ordre 1 : f(x) = f(a) + (x − a) f'(a) + (x − a) ε(x), ε(x) → 0 en a Classe Cⁿ sur I : les n premières dérivées existent et sont continues sur I (eˣ est C^∞)

3

Règles : composée, produit (Leibniz), dérivées partielles

diapos 14 à 17 · 40 min
L'idée. Pour une fonction composée, on dérive l'extérieur en gardant l'intérieur, puis on multiplie par la dérivée de l'intérieur. Pour une fonction de plusieurs variables, on dérive par rapport à une variable en figeant les autres.
Dérivation en chaîne : [f(g(x))]' = f'(g(x)) · g'(x) dy/dx = dy/du · du/dx Produit (Leibniz, n = 1) : (fg)' = f'g + fg' Dérivée partielle : ∂f/∂x (x, y) = lim (h→0) [f(x + h, y) − f(x, y)] / h (y figé)
Exemple corrigé · diapos 14, 16 et 17
Voir la correction
f(x) = (2x³ − 5x + 4)⁵ → f'(x) = 5(2x³ − 5x + 4)⁴ (6x² − 5) g(x) = (ln x)⁷ → g'(x) = 7 (ln x)⁶ / x h(x) = sin²(3x) → h'(x) = 2 sin(3x) × 3 cos(3x) = 3 sin(6x) f(x) = eˣ arcsin x → f'(x) = eˣ arcsin x + eˣ / √(1 − x²) g(x) = x² ln(1 + x²) → g'(x) = 2x ln(1 + x²) + 2x³/(1 + x²) f(x, y) = x² + 3xy + 2y² → ∂f/∂x = 2x + 3y ; ∂f/∂y = 3x + 4y
Exemple corrigé · fiche d'exercices 2, exercices 2 et 3
Voir la correction
sin(3x² + 2x) : ℝ, dérivable sur ℝ, dérivée (6x + 2) cos(3x² + 2x) √(x² + 1) : ℝ (x² + 1 > 0), dérivable sur ℝ, dérivée x / √(x² + 1) arctan(2x − 1) : ℝ, dérivable sur ℝ, dérivée 2 / (1 + (2x − 1)²) f paire ⇒ f' impaire ; f impaire ⇒ f' paire (dériver f(−x) = ±f(x))
4

Étude de fonction, Rolle et accroissements finis

diapos 18 à 21 · 35 min
L'idée. Le signe de f' donne le sens de variation. Un extremum (où f est dérivable) annule f', mais f'(a) = 0 ne suffit pas : x³ en 0 n'a pas d'extremum.
f' > 0 sur I ⇒ f strictement croissante ; f' < 0 sur I ⇒ f strictement décroissante Point critique : f'(a) = 0, ou f' n'existe pas en a (f définie en a) Fermat : extremum local en a et f dérivable en a ⇒ f'(a) = 0 (réciproque fausse) Sur [a, b] fermé (f continue) : les extrema sont aux points critiques de ]a, b[ ou en a, b Rolle : f continue sur [a, b], dérivable sur ]a, b[, f(a) = f(b) ⇒ ∃ c ∈ ]a, b[, f'(c) = 0 Accroissements finis : ∃ c ∈ ]a, b[, f(b) − f(a) = f'(c)(b − a)
Exemple corrigé · fiche d'exercices 2, exercice 4

f(x) = x³ − 3ax, a > 0. Points critiques, variations, extrema ?

Voir la correction
f'(x) = 3x² − 3a = 3(x − √a)(x + √a) → points critiques ±√a f croissante sur ]−∞, −√a], décroissante sur [−√a, √a], croissante sur [√a, +∞[ maximum local f(−√a) = 2a√a ; minimum local f(√a) = −2a√a a = 0 : f(x) = x³, f'(0) = 0 mais pas d'extremum (f toujours croissante)

Dérivées d'ordre supérieur, convexité

diapos 22 à 31 · 40 min
L'idée. f' est la vitesse de variation, f'' l'accélération (la courbure). Si f'' ≥ 0, la courbe est tournée vers le haut : f est convexe et reste au-dessus de ses tangentes.
(eˣ)⁽ⁿ⁾ = eˣ (cos x)⁽ⁿ⁾ = cos(x + nπ/2) (sin x)⁽ⁿ⁾ = sin(x + nπ/2) (x^p)⁽ⁿ⁾ = p(p − 1)…(p − n + 1) x^(p−n) si n < p ; p! si n = p ; 0 si n > p (1/x^p)⁽ⁿ⁾ = (−1)ⁿ p(p + 1)…(p + n − 1) / x^(p+n) Leibniz : (fg)⁽ⁿ⁾ = Σ (k = 0 à n) C(n, k) f⁽ᵏ⁾ g⁽ⁿ⁻ᵏ⁾ C(n, k) = n! / (k!(n − k)!)
Convexe : f((1 − λ)x + λy) ≤ (1 − λ)f(x) + λf(y) (courbe sous ses cordes) Concave : inégalité inverse (courbe au-dessus de ses cordes) ; ax + b est les deux f deux fois dérivable : f'' ≥ 0 sur I ⇔ f convexe ; f'' ≤ 0 sur I ⇔ f concave Convexe ⇒ pentes des sécantes croissantes : a < b < c ⇒ [f(b) − f(a)]/(b − a) ≤ [f(c) − f(a)]/(c − a) ≤ [f(c) − f(b)]/(c − b)
Exemple corrigé · diapos 26, 28 et 30
Voir la correction
Leibniz n = 2 : (fg)'' = f''g + 2f'g' + fg'' Leibniz n = 3 : (fg)''' = f'''g + 3f''g' + 3f'g'' + fg''' f(x) = x² eˣ : seuls k = 0, 1, 2 comptent (x² dérivé 3 fois = 0) f⁽ⁿ⁾(x) = eˣ (x² + 2nx + n(n − 1)) |x| est convexe sur ℝ (inégalité triangulaire), sans être dérivable en 0 ln x ≤ x − 1 : ln'' = −1/x² < 0, ln est concave, donc sous sa tangente en 1 (y = x − 1)

Approximation linéaire, différentielle, propagation d'erreur

diapos 32 à 39 · 40 min
L'idée. Tout près de a, la courbe se confond avec sa tangente : on remplace f par une fonction affine, facile à calculer. La même idée donne l'erreur sur un résultat calculé à partir de mesures imprécises.
Linéarisation en a : f(a + h) ≈ f(a) + f'(a) h (h petit) Différentielle : df = f'(x) dx ; Δf ≈ df Erreur absolue : |Δy| ≈ |f'(x)| |Δx| Erreur relative : |Δy|/|y| ≈ |x f'(x) / f(x)| × |Δx|/|x|
Exemple corrigé · diapos 33 et 35
Voir la correction
Avion : h(31) ≈ h(30) + h'(30) × 1 = 330 + 11,7 = 341,7 m √4,1 : f(x) = √x, a = 4, f(4) = 2, f'(4) = 1/(2√4) = 1/4 √4,1 ≈ 2 + 0,1/4 = 2,025 (valeur exacte 2,02485…)
Exemple corrigé · diapos 38 et 39

R = U/I avec U = 12,0 V (dU = 0,1 V) et I = 2,00 A (dI = 0,02 A). Puis E = ½mv², m = 1000 kg, v = 100 m/s, dv = 2 m/s.

Voir la correction
R = 12 / 2 = 6 Ω dR = dU/I − U dI/I² → majoration : |ΔR| ≈ 0,1/2 + 12 × 0,02/4 = 0,05 + 0,06 = 0,11 Ω (en relatif : ΔR/R ≈ ΔU/U + ΔI/I = 0,83 % + 1 % = 1,83 %) E(102) − E(100) = ½ × 1000 × (102² − 100²) = 202 000 J dE = m v dv = 1000 × 100 × 2 = 200 000 J (écart de 1 % : l'approximation est bonne)

Optimisation et phénomènes de variation

diapos 40 à 44 · 35 min
L'idée. On traduit la situation en une fonction d'une seule variable, on fixe son domaine, puis on cherche où la dérivée s'annule (et on compare avec les bornes).
Équation différentielle simple : y' = ky → y(t) = y(0) e^(kt) (croissance de population) Refroidissement : T'(t) = −k (T(t) − T_amb), k > 0 → T(t) = T_amb + (T₀ − T_amb) e^(−kt)
Exemple corrigé · le panier (diapo 41)

Plaque de 20 × 30 cm ; on découpe un carré de côté x à chaque coin et on plie les bords.

Voir la correction
0 < x < 10 (la largeur 20 − 2x doit rester positive) V(x) = x (20 − 2x)(30 − 2x) = 4x³ − 100x² + 600x V'(x) = 12x² − 200x + 600 = 0 → x = (200 − √11 200)/24 ≈ 3,92 cm (l'autre racine, 12,7 cm, sort du domaine) V_max ≈ 1056 cm³
Exemple corrigé · la boîte cylindrique (diapo 44)

Cylindre fermé de volume V = 1000 cm³ : dimensions qui minimisent la surface de métal ?

Voir la correction
V = πr²h = 1000 → h = 1000 / (πr²) S(r) = 2πr² + 2πrh = 2πr² + 2000/r S'(r) = 4πr − 2000/r² = 0 → r³ = 500/π → r ≈ 5,42 cm ; h = 2r ≈ 10,84 cm S_min ≈ 554 cm² (la hauteur optimale est égale au diamètre)

Méthode et résultat

ℓ est la droite passant par (0, r(0)) et (6, r(6)), donc g(0) = g(6) = 0 et Rolle donne c. r'(t) = −½ e^(−t/12) et ℓ' = (6e^(−1/2) − 6)/6 = e^(−1/2) − 1. r'(c) = ℓ' donne c = −12 ln(2(1 − e^(−1/2))) ≈ 2,87 jours : la tangente y est parallèle à la corde.
