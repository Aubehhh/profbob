Chapitre 1 · Nombres complexes

Définition et opérations

z = a + ib avec a, b ∈ ℝ et i² = −1 a = Re(z) : partie réelle ; b = Im(z) : partie imaginaire z = z' ⇔ Re(z) = Re(z') et Im(z) = Im(z') Conjugué : z* = z̄ = a − ib
Propriétés du conjugué : conj(z̄) = z Re z = (z + z̄)/2 Im z = (z − z̄)/(2i) z ∈ ℝ ⇔ Im z = 0 ⇔ z = z̄ z ∈ iℝ ⇔ Re z = 0 ⇔ z = −z̄ conj(z + z') = z̄ + z̄' conj(z z') = z̄ z̄' conj(z'/z) = z̄'/z̄ z z̄ = (Re z)² + (Im z)² = a² + b²
Addition : (a₁ + ib₁) + (a₂ + ib₂) = (a₁ + a₂) + i(b₁ + b₂) Multiplication : (a₁ + ib₁)(a₂ + ib₂) = (a₁a₂ − b₁b₂) + i(a₁b₂ + b₁a₂) Division : on multiplie en haut et en bas par le conjugué du dénominateur z₁/z₂ = [(a₁a₂ + b₁b₂) + i(b₁a₂ − a₁b₂)] / (a₂² + b₂²)

Plan complexe, module, argument, forme trigonométrique

Module : |z| = √(a² + b²) (Pythagore) Argument : θ = arg(z), en radians, tan θ = b/a Forme trigonométrique : z = r(cos θ + i sin θ) avec r = |z|, θ = arg(z) a = r cos θ ; b = r sin θ
Produit : |z₁z₂| = |z₁| |z₂| et arg(z₁z₂) = arg z₁ + arg z₂

Forme exponentielle, formule d'Euler, De Moivre

Formule d'Euler : e^(iθ) = cos θ + i sin θ Forme exponentielle : z = r e^(iθ) |e^(iθ)| = 1 conj(e^(iθ)) = e^(−iθ) = 1/e^(iθ) e^(i(θ+θ')) = e^(iθ) e^(iθ') e^(iθ) = 1 ⇔ θ = 2kπ, k ∈ ℤ identité d'Euler : e^(iπ) + 1 = 0
r₁e^(iθ) × r₂e^(iθ') = (r₁r₂) e^(i(θ+θ')) r₂e^(iθ) / r₁e^(iθ') = (r₂/r₁) e^(i(θ−θ')) zⁿ = (re^(iθ))ⁿ = rⁿ e^(inθ) De Moivre : (cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ) Exponentielle complexe : e^z = e^(Re z) e^(i Im z)

Racines carrées et racines n-ièmes

Racine carrée Z = A + iB de z = a + ib (Z² = z) : A² + B² = √(a² + b²) (|Z|² = |z|) A² − B² = a (Re Z² = Re z) AB du signe de b (Im Z² = 2AB = b)
Racines n-ièmes de l'unité (zⁿ = 1) : z_k = e^(i2kπ/n), k = 0, 1, …, n − 1 Racines n-ièmes de ω = re^(iθ) : z_k = r^(1/n) e^(i(θ + 2kπ)/n), k = 0, …, n − 1

Équations du second degré et polynômes

az² + bz + c = 0 (a, b, c ∈ ℂ, a ≠ 0) ; Δ = b² − 4ac Δ = 0 : racine double z₀ = −b/(2a) Δ ≠ 0 : δ une racine carrée de Δ → z₁ = (−b − δ)/(2a) ; z₂ = (−b + δ)/(2a)
Division euclidienne : A = BQ + R avec deg R < deg B (Q et R uniques) Hörner (racine r connue) : on recopie le 1er coefficient, puis à chaque colonne (nombre du bas à gauche) × r + coefficient du haut ; la dernière case doit valoir 0 la ligne du bas donne les coefficients de P(x)/(x − r)

Applications aux circuits : phaseurs et impédances

v(t) = V_m cos(ωt + φ) → phaseur Ṽ = V_m e^(jφ) = V_m ∠φ = V_m cos φ + j V_m sin φ Loi d'Ohm : Ṽ = Z Ĩ (convention récepteur) Z_R = R Z_L = jLω (tension en avance de π/2) Z_C = 1/(jCω) = −j/(Cω) (courant en avance de π/2) Série : Z = Σ Z_k Parallèle : 1/Z = Σ 1/Z_k (admittance Y = 1/Z)

Chapitre 2 · Calcul différentiel

Continuité

f continue en c : ∀ε > 0, ∃η > 0, ∀x ∈ D_f, |x − c| < η ⇒ |f(x) − f(c)| < ε c'est-à-dire lim (x→c) f(x) = f(c) continue à gauche : même chose avec c − η < x < c ; à droite : avec c < x < c + η

Dérivabilité et dérivées usuelles

f'(a) = lim (h→0) [f(a + h) − f(a)] / h Développement limité d'ordre 1 : f(x) = f(a) + (x − a) f'(a) + (x − a) ε(x), ε(x) → 0 en a Classe Cⁿ sur I : les n premières dérivées existent et sont continues sur I (eˣ est C^∞)

Règles : composée, produit (Leibniz), dérivées partielles

Dérivation en chaîne : [f(g(x))]' = f'(g(x)) · g'(x) dy/dx = dy/du · du/dx Produit (Leibniz, n = 1) : (fg)' = f'g + fg' Dérivée partielle : ∂f/∂x (x, y) = lim (h→0) [f(x + h, y) − f(x, y)] / h (y figé)

Étude de fonction, Rolle et accroissements finis

f' > 0 sur I ⇒ f strictement croissante ; f' < 0 sur I ⇒ f strictement décroissante Point critique : f'(a) = 0, ou f' n'existe pas en a (f définie en a) Fermat : extremum local en a et f dérivable en a ⇒ f'(a) = 0 (réciproque fausse) Sur [a, b] fermé (f continue) : les extrema sont aux points critiques de ]a, b[ ou en a, b Rolle : f continue sur [a, b], dérivable sur ]a, b[, f(a) = f(b) ⇒ ∃ c ∈ ]a, b[, f'(c) = 0 Accroissements finis : ∃ c ∈ ]a, b[, f(b) − f(a) = f'(c)(b − a)

Dérivées d'ordre supérieur, convexité

(eˣ)⁽ⁿ⁾ = eˣ (cos x)⁽ⁿ⁾ = cos(x + nπ/2) (sin x)⁽ⁿ⁾ = sin(x + nπ/2) (x^p)⁽ⁿ⁾ = p(p − 1)…(p − n + 1) x^(p−n) si n < p ; p! si n = p ; 0 si n > p (1/x^p)⁽ⁿ⁾ = (−1)ⁿ p(p + 1)…(p + n − 1) / x^(p+n) Leibniz : (fg)⁽ⁿ⁾ = Σ (k = 0 à n) C(n, k) f⁽ᵏ⁾ g⁽ⁿ⁻ᵏ⁾ C(n, k) = n! / (k!(n − k)!)
Convexe : f((1 − λ)x + λy) ≤ (1 − λ)f(x) + λf(y) (courbe sous ses cordes) Concave : inégalité inverse (courbe au-dessus de ses cordes) ; ax + b est les deux f deux fois dérivable : f'' ≥ 0 sur I ⇔ f convexe ; f'' ≤ 0 sur I ⇔ f concave Convexe ⇒ pentes des sécantes croissantes : a < b < c ⇒ [f(b) − f(a)]/(b − a) ≤ [f(c) − f(a)]/(c − a) ≤ [f(c) − f(b)]/(c − b)

Approximation linéaire, différentielle, propagation d'erreur

Linéarisation en a : f(a + h) ≈ f(a) + f'(a) h (h petit) Différentielle : df = f'(x) dx ; Δf ≈ df Erreur absolue : |Δy| ≈ |f'(x)| |Δx| Erreur relative : |Δy|/|y| ≈ |x f'(x) / f(x)| × |Δx|/|x|

Optimisation et phénomènes de variation

Équation différentielle simple : y' = ky → y(t) = y(0) e^(kt) (croissance de population) Refroidissement : T'(t) = −k (T(t) − T_amb), k > 0 → T(t) = T_amb + (T₀ − T_amb) e^(−kt)

Chapitre 3 · Techniques fondamentales du calcul intégral

Primitives

F primitive de f sur I : F'(x) = f(x) pour tout x ∈ I ∫ f(x) dx = F(x) + C (intégrale indéfinie) Linéarité : ∫ (λf + μg) = λ ∫ f + μ ∫ g

Intégrale définie et propriétés

∫ₐᵇ f(x) dx = F(b) − F(a) Inversion des bornes : ∫ₐᵇ f = −∫ᵦᵃ f bornes égales : ∫ₐᵃ f = 0 Chasles : ∫ₐᵇ f = ∫ₐᶜ f + ∫꜀ᵇ f Positivité : f ≥ 0 sur [a, b] ⇒ ∫ₐᵇ f ≥ 0 Valeur moyenne : f̄ = (1/(b − a)) ∫ₐᵇ f(x) dx

Sommes de Riemann et fonctions en escalier

Δx = (b − a)/n Somme par la droite : S_n = Δx × Σ (k = 1 à n) f(a + kΔx) Somme par la gauche : S_n = Δx × Σ (k = 0 à n − 1) f(a + kΔx) Intégrale de Riemann : ∫ₐᵇ f(x) dx = lim (n→∞) ((b − a)/n) Σ f(a + k(b − a)/n) Fonction en escalier (valeur c_i sur [x_i ; x_(i+1)[) : ∫ₐᵇ φ = Σ c_i (x_(i+1) − x_i)

Théorème fondamental de l'analyse

f continue sur [a, b], F(x) = ∫ₐˣ f(t) dt ⇒ F'(x) = f(x) F primitive de f ⇒ ∫ₐᵇ f(x) dx = F(b) − F(a) (1) trouver une primitive ; (2) l'évaluer aux bornes ; (3) faire la différence

Changement de variable et intégration par parties

Changement de variable : u = g(x), du = g'(x) dx, on intègre en u, puis on remplace u par g(x) Intégration par parties : ∫ u dv = uv − ∫ v du ∫ₐᵇ u v' = [uv]ₐᵇ − ∫ₐᵇ u' v Règle ALPES pour choisir u (on dérive u) : Arcsin… → Log → Polynôme → Exponentielle → Sinus/cosinus u = la fonction la plus à gauche de ALPES ; dv = le reste

Décomposition en éléments simples

Un facteur (x − a) au dénominateur → A/(x − a) Un facteur (x − a)² au dénominateur → A/(x − a) + B/(x − a)² (une fraction par degré) Un facteur x² + px + q sans racine réelle → (Bx + C)/(x² + px + q) On trouve les numérateurs en remettant au même dénominateur (ou en remplaçant x par les racines).

Intégrales doubles et applications

∬_R f(x, y) dA = ∫ₐᵇ ( ∫꜀ᵈ f(x, y) dy ) dx (R = [a, b] × [c, d]) Si les bornes de y dépendent de x, on garde l'intégrale en y à l'intérieur.

Chapitre 4 · Trigonométrie et fonctions usuelles

Cercle trigonométrique et fonctions circulaires

sin θ = opposé/hypoténuse cos θ = adjacent/hypoténuse tan θ = opposé/adjacent csc θ = 1/sin θ sec θ = 1/cos θ cot θ = 1/tan θ Cercle trigonométrique : x² + y² = 1 x ≡ y [2π] ⇔ ∃k ∈ ℤ, x = y + 2kπ
cos' = −sin ; sin' = cos ; |sin x| ≤ |x| tan x = sin x / cos x pour x ≠ π/2 + kπ ; tan' x = 1 + tan² x = 1/cos² x

Identités et formules de trigonométrie

Pythagore : sin² θ + cos² θ = 1 ; 1 + tan² θ = sec² θ ; 1 + cot² θ = csc² θ Sommes et différences : sin(A ± B) = sin A cos B ± cos A sin B cos(A ± B) = cos A cos B ∓ sin A sin B tan(A ± B) = (tan A ± tan B) / (1 ∓ tan A tan B) Angles doubles : sin 2θ = 2 sin θ cos θ ; cos 2θ = cos² θ − sin² θ ; tan 2θ = 2 tan θ / (1 − tan² θ) Angles moitiés : sin(θ/2) = ±√((1 − cos θ)/2) ; cos(θ/2) = ±√((1 + cos θ)/2) Produits : 2 cos a cos b = cos(a + b) + cos(a − b) 2 sin a cos b = sin(a + b) + sin(a − b) 2 sin a sin b = cos(a − b) − cos(a + b)

Équations trigonométriques

sin x = sin a ⇔ x = a + 2kπ ou x = π − a + 2kπ cos x = cos a ⇔ x = a + 2kπ ou x = −a + 2kπ tan x = tan a ⇔ x = a + kπ

Puissances, exponentielle et logarithmes

(xy)ⁿ = xⁿyⁿ ; x^(m+n) = x^m xⁿ ; (x^m)ⁿ = x^(mn) ; racine n-ième : x^(1/n) eˣ = lim (n→∞) (1 + x/n)ⁿ ; domaine ℝ, image ]0, +∞[ ; (eˣ)' = eˣ ; ∫ eˣ dx = eˣ + C lim (x→−∞) eˣ = 0 ; lim (x→+∞) eˣ = +∞ log_b(x) défini pour x > 0 : log_b(1) = 0 ; log_b(b) = 1 log_b(xy) = log_b x + log_b y ; log_b(xⁿ) = n log_b x (log_b x)' = 1/(x ln b) ; ∫ log_b x dx = (x ln x − x)/ln b + C ln = log_e : domaine ]0, +∞[, image ℝ ; (ln x)' = 1/x ; ∫ ln x dx = x ln x − x + C ; lim (x→0⁺) ln x = −∞

Fonctions hyperboliques

sinh x = (eˣ − e⁻ˣ)/2 cosh x = (eˣ + e⁻ˣ)/2 tanh x = sinh x / cosh x coth x = cosh x / sinh x sech x = 1/cosh x csch x = 1/sinh x cosh² x − sinh² x = 1 sinh' = cosh ; cosh' = sinh ; tanh' = sech² ; coth' = −csch² ; sech' = −sech tanh ; csch' = −csch coth ∫ sinh = cosh + C ; ∫ cosh = sinh + C ; ∫ tanh = ln(cosh x) + C ; ∫ sech² = tanh + C sinh 2x = 2 sinh x cosh x ; cosh 2x = cosh² x + sinh² x = 2 cosh² x − 1 = 1 + 2 sinh² x tanh 2x = 2 tanh x / (1 + tanh² x)
