Chapitre 1 · Notions de base en électricité

Tension et courant électrique

i(t) = dQ(t) / dt i en A ; Q en coulombs (C) ; t en s
Majuscules et minuscules. Une grandeur qui dépend du temps s'écrit en minuscule (u, i, p). Une grandeur constante s'écrit en majuscule (U, I, P).

Relations puissance / énergie

Puissance constante : w = P × T Constante par intervalles : w = P₁T₁ + P₂T₂ + P₃T₃ + … = <p(t)> × T Cas général : w = ∫₀ᵀ p(t) dt = <p(t)> × T Puissance moyenne (active) : <p(t)> = (1/T) ∫₀ᵀ p(t) dt w en J ; P en W ; T en s (1 kWh = 3,6×10⁶ J)
La puissance moyenne est aussi appelée puissance active. Elle est proportionnelle à l'aire algébrique entre l'axe et la courbe de p(t).

Chapitre 2 · Circuits alimentés en continu

Éléments d'un circuit et conventions de fléchage

Changer de convention change le signe de la relation entre u et i : en récepteur u = R i, en générateur u = −R i pour la même résistance.
Bilan de puissance : p = u × i convention récepteur : p > 0 → le dipôle reçoit (fonctionne en récepteur) convention générateur : p > 0 → le dipôle fournit (fonctionne en générateur)

Résistance d'un conducteur et influence de la température

R = ρ × l / S R en Ω ; ρ (résistivité) en Ω·m ; l en m ; S en m²
Résistivité à θ °C : ρ_θ = ρ₀ (1 + a₀ θ) (relation affine) Résistance à θ °C : R_θ = R₀ (1 + a₀ θ) ρ₀, R₀ : valeurs à 0 °C ; a₀ : coefficient de température (°C⁻¹) ; θ en °C

Loi d'Ohm, associations série et parallèle

Loi d'Ohm (convention récepteur) : u = R × i ; en continu : U = R × I U en V ; R en Ω ; I en A
Série (même courant) : R_éq = R₁ + R₂ + R₃ Parallèle (même tension) : 1/R_éq = 1/R₁ + 1/R₂ + 1/R₃ deux résistances en parallèle : R_éq = R₁R₂ / (R₁ + R₂)
Remarques du cours. En série, Réq est toujours plus grande que la plus grande des résistances. En parallèle, Réq est toujours plus petite que la plus petite.

Loi des mailles et loi des nœuds de Kirchhoff

Loi des mailles (LMK) : la somme algébrique des tensions le long d'une maille est nulle. On choisit un sens de parcours : une tension dont la flèche est dans ce sens compte +, sinon −. Loi des nœuds (LNK) : la somme algébrique des intensités à un nœud est nulle (somme des courants qui arrivent = somme des courants qui partent).

Diviseur de tension et diviseur de courant

Diviseur de tension (R₁ et R₂ en série, sortie à vide : I_s = 0) : V_s = V_e × R₂ / (R₁ + R₂) (tension aux bornes de R₂) Diviseur de courant (R₁ et R₂ en parallèle, courant total I) : i₁ = I × R₂ / (R₁ + R₂) (courant dans R₁ : c'est l'AUTRE résistance au numérateur)
Pour mémoriser. Tension : « la résistance dont on veut la tension, sur la somme ». Courant : « l'autre résistance, sur la somme ».

Chapitre 3 · Modèles électriques équivalents

Circuit à plusieurs mailles : la méthode de Kirchhoff

n nœuds, p courants inconnus (p branches) : n − 1 équations de nœuds p − (n − 1) équations de mailles (les autres équations ne seraient pas indépendantes)
Nœud A : i₁ + i₂ + i₃ = 0 (1) Maille A R₁ B E₂ R₂ A : −R₁i₁ + E₂ + R₂i₂ = 0 (2) Maille A R₂ E₂ B E₃ R₃ A : −R₂i₂ − E₂ + E₃ + R₃i₃ = 0 (3)

Théorème de superposition

i₁ = i₁E₂ + i₁E₃ (de même pour i₂ et i₃) Éteindre une source de tension = la remplacer par un fil (court-circuit) Éteindre une source de courant = la remplacer par un interrupteur ouvert

Théorème de Thévenin

u = E_T − R_T × i E_T : tension à vide (i = 0) R_T : résistance interne = pente de la caractéristique courant de court-circuit (u = 0) : I_cc = E_T / R_T

Théorème de Norton

u = R_N × (I_CC − i) Passage Thévenin ↔ Norton : I_CC = E_T / R_T R_N = R_T E_T = R_N × I_CC

Chapitre 4 · Circuits alimentés en sinusoïdal monophasé

Le signal sinusoïdal et sa représentation de Fresnel

v(t) = V̂ sin(ωt + φ) = V √2 sin(ωt + φ) V̂ (= V_max) : amplitude ; V : valeur efficace ω = 2πf = 2π/T : pulsation (rad·s⁻¹) ; f = 1/T (Hz) ; T : période (s) φ : phase à l'origine (rad) réseau : f = 50 Hz, T = 20 ms, V = 230 V, V̂ = 325 V
Fresnel. On dessine un vecteur de longueur proportionnelle à la valeur efficace, faisant avec l'axe un angle égal à la phase à l'origine. On note la grandeur avec une flèche : V⃗₁. C'est pratique pour ajouter ou soustraire des tensions, mais cela ne marche qu'à fréquence commune et pour des sinus parfaits, et on ne peut pas dessiner un produit de deux vecteurs.

L'outil mathématique : les nombres complexes

Forme algébrique : V = a + j b Forme polaire : V = [ρ ; θ] = ρ (cos θ + j sin θ) = ρ e^(jθ) ρ = √(a² + b²) (module = longueur du vecteur) a = ρ cos θ ; b = ρ sin θ ; θ = arctan(b/a) (argument) j = [1 ; π/2] : imaginaire pur de module 1, j² = −1
Addition, soustraction : sur la forme algébrique V₁ ± V₂ = (a₁ ± a₂) + j(b₁ ± b₂) Multiplication : V₁ × V₂ = [ρ₁ρ₂ ; θ₁ + θ₂] Division : V₁ / V₂ = [ρ₁/ρ₂ ; θ₁ − θ₂]

Le résistor et la valeur efficace

u_R(t) = R i_R(t) (continu : U_R = R I_R) En complexes : U_R = Z_R I_R avec Z_R = R = [R ; 0] φ_R = arg U_R − arg I_R = 0 : tension et courant en phase p_R(t) = u_R(t) × i_R(t) = R i_R²(t) = u_R²(t)/R ≥ 0
Puissance active : P = <p(t)> = (1/T) ∫₀ᵀ p(t) dt (à mi-hauteur entre p_max et p_min) Pour une résistance : P_R = Û_R² / (2R) = U_R² / R = R I_R² = U_R × I_R Valeur efficace (RMS) : U = √( (1/T) ∫₀ᵀ u²(t) dt ) = √<u²(t)> En sinusoïdal : U = Û / √2

L'inductance d'une bobine

u_L(t) = L × di_L(t)/dt Continu établi : u_L = 0 → la bobine se comporte comme un fil Sinusoïdal : U_L = Lω × I_L ; Z_L = jLω = [Lω ; π/2] le courant est en retard de π/2 (quadrature retard) sur la tension Énergie stockée : w_L(t) = ½ L i_L²(t)
Puissances d'une inductance : P_L = U_L I_L cos(π/2) = 0 Q_L = U_L I_L = Lω I_L² = U_L² / (Lω) > 0 (consommée) [VAR] S_L = Q_L = U_L I_L ; facteur de puissance = 0 Associations : série L_éq = L₁ + L₂ + L₃ ; parallèle 1/L_éq = 1/L₁ + 1/L₂ + 1/L₃

Le condensateur

i_C(t) = C × du_C(t)/dt Continu : i_C = 0 → circuit ouvert Sinusoïdal : I_C = Cω × U_C ; Z_C = 1/(jCω) = −j/(Cω) = [1/(Cω) ; −π/2] le courant est en avance de π/2 (quadrature avance) sur la tension Énergie stockée : w_C(t) = ½ C u_C²(t)
Puissances d'un condensateur : P_C = 0 Q_C = −U_C I_C = −I_C² / (Cω) = −U_C² Cω < 0 (fournie) [VAR] S_C = U_C I_C = |Q_C| ; facteur de puissance = 0 Associations : série 1/C_éq = 1/C₁ + 1/C₂ + 1/C₃ ; parallèle C_éq = C₁ + C₂ + C₃

Associations d'impédances et circuit RLC série

Loi d'Ohm complexe : U = Z I Série : Z_éq = Z₁ + Z₂ + Z₃ Parallèle : 1/Z_éq = 1/Z₁ + 1/Z₂ + 1/Z₃ RLC série : Z_s = R + j(Lω − 1/(Cω)) |Z_s| = √(R² + (Lω − 1/(Cω))²) ; φ = arg Z_s = arctan((Lω − 1/(Cω)) / R)

Modèle de Thévenin d'une source sinusoïdale

Source parfaite : U reste constante quel que soit I Source réelle : U = E_T − Z_T × I Avec une charge Z_C : I = E_T / (Z_T + Z_C) ; U = E_T × Z_C / (Z_T + Z_C) (diviseur de tension)

Triangle des puissances et méthode de Boucherot

S = U × I = √(P² + Q²) [VA] (sert à dimensionner les fils) P = U I cos φ = S cos φ [W] Q = U I sin φ = S sin φ [VAR] tan φ = Q / P ; facteur de puissance PF = P / S = cos φ
Méthode de Boucherot (n récepteurs alimentés sous la même tension U) : P_T = P₁ + P₂ + … + P_N Q_T = Q₁ + Q₂ + … + Q_N (Q > 0 bobine, Q < 0 condensateur) S_T = √(P_T² + Q_T²) = U × I_T cos φ_T = P_T / S_T

Relever le facteur de puissance, appareils de mesure

Rendement : η = P_U / P_A → P_A = P_U / η Condensateur pour passer de φ à φ' (P inchangée) : Q_C = −P (tan φ − tan φ') C = P (tan φ − tan φ') / (U² ω) Courant après relèvement : I' = P / (U cos φ')

Chapitre 5 · Structure et propriétés d'un réseau triphasé équilibré

Structure d'un réseau triphasé

Réseau triphasé : 3 fils de phases (L1, L2, L3) + 1 fil de neutre (N) pour alimenter les récepteurs + 1 fil de protection (PE) relié à la terre pour protéger les personnes

Les tensions simples

v_1(t) = V √2 sin ωt v_2(t) = V √2 sin(ωt − 2π/3) v_3(t) = V √2 sin(ωt − 4π/3)
V₁ = [V ; 0°] V₂ = [V ; −120°] V₃ = [V ; −240°]
À retenir. Les trois vecteurs ont même longueur et sont à 120° : leur somme est nulle. À chaque instant, v1 + v2 + v3 = 0.

Les tensions composées

u_13(t) = v_1(t) − v_3(t) u_21(t) = v_2(t) − v_1(t) u_32(t) = v_3(t) − v_2(t)
u_13(t) = U √2 sin(ωt − π/6) u_21(t) = U √2 sin(ωt − 5π/6) u_32(t) = U √2 sin(ωt − 3π/2)
