Le signal sinusoïdal et sa représentation de Fresnel

diapos 3 à 7 · 30 min
L'idée. Un signal sinusoïdal est entièrement décrit par trois nombres : son amplitude (ou sa valeur efficace), sa fréquence et sa phase à l'origine. À fréquence commune, on le dessine comme un vecteur tournant : le vecteur de Fresnel.
v(t) = V̂ sin(ωt + φ) = V √2 sin(ωt + φ) V̂ (= V_max) : amplitude ; V : valeur efficace ω = 2πf = 2π/T : pulsation (rad·s⁻¹) ; f = 1/T (Hz) ; T : période (s) φ : phase à l'origine (rad) réseau : f = 50 Hz, T = 20 ms, V = 230 V, V̂ = 325 V

Déphasage. v₂(t) = V̂₂ sin(ωt − π/6) a une phase à l'origine de −π/6 = −30° : v₂ est en retard de 30° sur v₁(t) = V̂₁ sin ωt. Une phase positive correspond à une avance.

Fresnel. On dessine un vecteur de longueur proportionnelle à la valeur efficace, faisant avec l'axe un angle égal à la phase à l'origine. On note la grandeur avec une flèche : V⃗₁. C'est pratique pour ajouter ou soustraire des tensions, mais cela ne marche qu'à fréquence commune et pour des sinus parfaits, et on ne peut pas dessiner un produit de deux vecteurs.

Une tension v(t) = 325 sin(100πt) a pour fréquence :

ω = 100π = 2πf, donc f = 50 Hz.

L'outil mathématique : les nombres complexes

diapos 8 à 10 · 35 min
L'idée. Le vecteur de Fresnel devient un nombre complexe : on peut alors calculer au lieu de dessiner. On note un complexe souligné : V.
Forme algébrique : V = a + j b Forme polaire : V = [ρ ; θ] = ρ (cos θ + j sin θ) = ρ e^(jθ) ρ = √(a² + b²) (module = longueur du vecteur) a = ρ cos θ ; b = ρ sin θ ; θ = arctan(b/a) (argument) j = [1 ; π/2] : imaginaire pur de module 1, j² = −1
Addition, soustraction : sur la forme algébrique V₁ ± V₂ = (a₁ ± a₂) + j(b₁ ± b₂) Multiplication : V₁ × V₂ = [ρ₁ρ₂ ; θ₁ + θ₂] Division : V₁ / V₂ = [ρ₁/ρ₂ ; θ₁ − θ₂]
Piège : arctan ne suffit pas toujours. arctan(b/a) donne un angle entre −90° et +90°. Si la partie réelle a est négative, il faut ajouter 180° (le point est à gauche de l'axe imaginaire).
Exemple corrigé · exercice de la diapo 10 (et diapo 7)

v₁(t) = V₁√2 sin ωt et v₂(t) = V₂√2 sin(ωt + 2π/3), avec V₁ = V₂ = 230 V. Calcule U₁₂ = V₁ − V₂ : valeur efficace et phase à l'origine.

Voir la correction
V₁ = [230 ; 0] = 230 + j 0 V₂ = [230 ; 120°] = 230 cos 120° + j 230 sin 120° = −115 + j 199,2 U₁₂ = V₁ − V₂ = 345 − j 199,2 |U₁₂| = √(345² + 199,2²) = 398,4 V (= 230 √3) arg U₁₂ = arctan(−199,2 / 345) = −30°

On retrouve un résultat du triphasé : la différence de deux tensions de 230 V décalées de 120° vaut 230√3 ≈ 400 V.

Le résistor et la valeur efficace

diapos 11 à 21 · 40 min
L'idée. Dans une résistance, courant et tension sont en phase et la puissance est toujours consommée. La valeur efficace est la valeur continue qui chaufferait autant la même résistance.
u_R(t) = R i_R(t) (continu : U_R = R I_R) En complexes : U_R = Z_R I_R avec Z_R = R = [R ; 0] φ_R = arg U_R − arg I_R = 0 : tension et courant en phase p_R(t) = u_R(t) × i_R(t) = R i_R²(t) = u_R²(t)/R ≥ 0

La puissance instantanée a une fréquence double de celle de la tension et ne prend que des valeurs positives : la résistance consomme toujours, et transforme la puissance en chaleur (effet Joule).

Puissance active : P = <p(t)> = (1/T) ∫₀ᵀ p(t) dt (à mi-hauteur entre p_max et p_min) Pour une résistance : P_R = Û_R² / (2R) = U_R² / R = R I_R² = U_R × I_R Valeur efficace (RMS) : U = √( (1/T) ∫₀ᵀ u²(t) dt ) = √<u²(t)> En sinusoïdal : U = Û / √2
Piège. U = Û/√2 n'est vrai qu'en sinusoïdal. Pour un carré symétrique d'amplitude E, u² vaut toujours E² : la valeur efficace vaut E, pas E/√2.
Exemple corrigé · exercices N°1 et N°2 (diapo 18)

Valeur efficace d'un carré symétrique d'amplitude E ? Un radiateur porte 230 V, 1000 W : courant efficace et résistance ?

Voir la correction
Carré : u²(t) = E² à tout instant → U = √E² = E Radiateur : I = P / U = 1000 / 230 = 4,35 A R = U² / P = 230² / 1000 = 52,9 Ω
Exemple corrigé · source continue et source sinusoïdale (diapos 19 et 20)

Une tension sinusoïdale d'amplitude V̂ = 325 V, puis une source V₁ = 24 V efficace, 50 Hz, qui alimente R = 47 Ω. Valeur efficace, pulsation, puissance, et tension continue qui chaufferait autant ?

Voir la correction
V = 325 / √2 = 229,8 V 24 V efficace : V̂ = 24 √2 = 33,9 V ; T = 20 ms ; ω = 2π × 50 = 314 rad·s⁻¹ P = V² / R = 24² / 47 = 12,3 W Même puissance en continu : il faut 24 V continus (c'est la définition de la valeur efficace).
4

L'inductance d'une bobine

diapos 22 à 35 · 50 min
L'idée. Une bobine s'oppose aux variations du courant. En continu établi, c'est un simple fil ; en sinusoïdal, le courant est en retard d'un quart de période sur la tension, et la bobine ne consomme aucune puissance active.

Une bobine réelle est modélisée par une inductance L (en henry, H) en série avec la résistance R de son fil. Elle crée un champ magnétique, génère une tension quand le champ varie, stocke et restitue de l'énergie, et filtre les variations de courant.

u_L(t) = L × di_L(t)/dt Continu établi : u_L = 0 → la bobine se comporte comme un fil Sinusoïdal : U_L = Lω × I_L ; Z_L = jLω = [Lω ; π/2] le courant est en retard de π/2 (quadrature retard) sur la tension Énergie stockée : w_L(t) = ½ L i_L²(t)
Puissances d'une inductance : P_L = U_L I_L cos(π/2) = 0 Q_L = U_L I_L = Lω I_L² = U_L² / (Lω) > 0 (consommée) [VAR] S_L = Q_L = U_L I_L ; facteur de puissance = 0 Associations : série L_éq = L₁ + L₂ + L₃ ; parallèle 1/L_éq = 1/L₁ + 1/L₂ + 1/L₃
Exemple corrigé · exercice N°2 (diapo 33)

L = 0,9 H alimentée par uL(t) = 325 sin ωt, f = 50 Hz. Valeur efficace, impédance, courant, puissances ?

Voir la correction
U_L = 325 / √2 = 229,8 V ω = 2π × 50 = 314,2 rad·s⁻¹ Z_L = jLω = [0,9 × 314,2 ; 90°] = [282,7 Ω ; 90°] I_L = U_L / Z_L = [229,8 / 282,7 ; 0 − 90°] = [0,813 A ; −90°] P_L = 0 (inductance pure) Q_L = U_L I_L = 229,8 × 0,813 = 187 VAR ; S_L = 187 VA
Exemple corrigé · exercice N°1 (diapo 32) : courant triangulaire

L = 0,7 H, courant triangulaire de −5 A à +5 A, f = 1 kHz. Période, tension sur chaque demi-période, énergie maximale stockée ?

Voir la correction
T = 1 / f = 1 ms 0 < t < T/2 : i monte de −5 à +5 A en 0,5 ms → di/dt = 10 / 0,5×10⁻³ = 2×10⁴ A·s⁻¹ u_L = 0,7 × 2×10⁴ = 14 000 V T/2 < t < T : i redescend → u_L = −14 000 V (créneau) W_max = ½ × 0,7 × 5² = 8,75 J

Les valeurs sont énormes car le courant varie très vite : c'est pour cela qu'on ne coupe jamais brutalement le courant dans une bobine (étincelles).

Exemple corrigé · exercice N°3 (diapo 35) : circuit R, L série

R = 165 Ω et L = 0,7 H en série sous V = 230 V, 50 Hz. Impédance, courant, tensions UR et UL ?

Voir la correction
Lω = 0,7 × 314,2 = 219,9 Ω Z_éq = R + jLω = 165 + j 219,9 = [274,9 Ω ; 53,1°] I = V / Z_éq = [230 / 274,9 ; −53,1°] = [0,837 A ; −53,1°] U_R = R I = 138,0 V ; U_L = Lω I = 184,0 V (138,0² + 184,0² = 230² : U_R + U_L = V en vecteurs, pas en valeurs efficaces)
Piège. 138 + 184 ≠ 230 : les valeurs efficaces ne s'ajoutent pas en sinusoïdal, ce sont les vecteurs (ou les complexes) qui s'ajoutent.
5

Le condensateur

diapos 36 à 44 · 40 min
L'idée. C'est l'inverse de la bobine : un condensateur s'oppose aux variations de la tension. En continu, il bloque le courant ; en sinusoïdal, le courant est en avance d'un quart de période et le condensateur fournit de la puissance réactive.

Deux surfaces conductrices séparées par un isolant (air, céramique, papier, électrolyte…). Il stocke de l'énergie, lisse les variations de tension et crée un champ électrique.

i_C(t) = C × du_C(t)/dt Continu : i_C = 0 → circuit ouvert Sinusoïdal : I_C = Cω × U_C ; Z_C = 1/(jCω) = −j/(Cω) = [1/(Cω) ; −π/2] le courant est en avance de π/2 (quadrature avance) sur la tension Énergie stockée : w_C(t) = ½ C u_C²(t)
Puissances d'un condensateur : P_C = 0 Q_C = −U_C I_C = −I_C² / (Cω) = −U_C² Cω < 0 (fournie) [VAR] S_C = U_C I_C = |Q_C| ; facteur de puissance = 0 Associations : série 1/C_éq = 1/C₁ + 1/C₂ + 1/C₃ ; parallèle C_éq = C₁ + C₂ + C₃
Piège : les associations de condensateurs sont « à l'envers ». Les capacités s'ajoutent en parallèle et se combinent comme des inverses en série : c'est le contraire des résistances et des inductances.
Exemple corrigé · exercice N°2 (diapo 43)

C = 12 µF sous V = 230 V, 50 Hz, phase à l'origine nulle. Impédance, courant, puissances ?

Voir la correction
1/(Cω) = 1 / (12×10⁻⁶ × 314,2) = 265,3 Ω Z_C = [265,3 Ω ; −90°] ; U_C = [230 V ; 0] I_C = U_C / Z_C = [230 / 265,3 ; 0 + 90°] = [0,867 A ; +90°] Q_C = −U_C I_C = −199 VAR ; S_C = 199 VA
Exemple corrigé · exercice N°1 (diapo 42) : charge à courant constant

C = 1000 µF, initialement déchargé, chargé par ICC = 200 mA pendant 100 s. Tension atteinte et énergie stockée ?

Voir la correction
i_C constant : du_C/dt = I/C → u_C(t) = (I / C) × t (droite) u_C(100 s) = 0,2 × 100 / 1000×10⁻⁶ = 20 000 V W = ½ C u² = ½ × 10⁻³ × (2×10⁴)² = 2×10⁵ J

Les valeurs de l'énoncé donnent une tension irréaliste (aucun condensateur de 1000 µF ne tient 20 kV) : garde la méthode, la droite uC = I t / C.

En sinusoïdal, dans un condensateur, le courant est :

Z_C = [1/(Cω) ; −90°], donc arg I = arg U + 90°.

Associations d'impédances et circuit RLC série

diapos 45 et 46 · 35 min
L'idée. En complexes, les impédances s'associent exactement comme des résistances. Tout le reste (loi d'Ohm, diviseurs, Kirchhoff) marche pareil.
Loi d'Ohm complexe : U = Z I Série : Z_éq = Z₁ + Z₂ + Z₃ Parallèle : 1/Z_éq = 1/Z₁ + 1/Z₂ + 1/Z₃ RLC série : Z_s = R + j(Lω − 1/(Cω)) |Z_s| = √(R² + (Lω − 1/(Cω))²) ; φ = arg Z_s = arctan((Lω − 1/(Cω)) / R)
Exemple corrigé · exercice N°3 (diapo 46) : récepteur RLC série

R = 200 Ω, L = 2 H, C = 10 µF en série sous E = 230 V, 50 Hz (E origine des phases). Zs, courant, tensions UR, UL, UC ?

Voir la correction
Lω = 2 × 314,2 = 628,3 Ω ; 1/(Cω) = 1/(10⁻⁵ × 314,2) = 318,3 Ω Z_s = 200 + j(628,3 − 318,3) = 200 + j 310,0 |Z_s| = √(200² + 310,0²) = 368,9 Ω ; arg Z_s = arctan(310,0/200) = 57,2° I = E / Z_s = [230 / 368,9 ; −57,2°] = [0,623 A ; −57,2°] U_R = [124,7 V ; −57,2°] ; U_L = [391,7 V ; 32,8°] ; U_C = [198,4 V ; −147,2°]

UL = 391,7 V dépasse E = 230 V : c'est possible, car UL et UC sont en opposition et se compensent en partie.

Dans un RLC série, si Lω > 1/(Cω), le circuit est :

La partie imaginaire de Z_s est positive, donc φ > 0 : le courant est en retard.
7

Modèle de Thévenin d'une source sinusoïdale

diapos 47 et 48 · 20 min
L'idée. Comme en continu : une source réelle est une source parfaite ET en série avec une impédance interne ZT, et la tension de sortie baisse quand le courant augmente.
Source parfaite : U reste constante quel que soit I Source réelle : U = E_T − Z_T × I Avec une charge Z_C : I = E_T / (Z_T + Z_C) ; U = E_T × Z_C / (Z_T + Z_C) (diviseur de tension)
Exemple corrigé · exercice de la diapo 48

ET = 237 V (phase nulle), ZT = [1,87 Ω ; 42°], charge ZC = [44 Ω ; 42°]. Courant et tension ?

Voir la correction
Les deux impédances ont le même argument : leurs modules s'ajoutent directement Z_T + Z_C = [1,87 + 44 ; 42°] = [45,87 Ω ; 42°] I = 237 / [45,87 ; 42°] = [5,17 A ; −42°] U = Z_C I = [44 × 5,17 ; 42° − 42°] = [227,3 V ; 0°] Diviseur de tension : U = 237 × 44 / 45,87 = 227,3 V ✓
Piège. On n'ajoute les modules d'impédances que si elles ont le même argument. Sinon, il faut passer par la forme algébrique.

Triangle des puissances et méthode de Boucherot

diapos 27, 28 et 49 à 51 · 45 min
L'idée. P (active, en W) et Q (réactive, en VAR) forment les côtés d'un triangle rectangle dont l'hypoténuse est S (apparente, en VA). Pour plusieurs récepteurs, on additionne les P entre eux et les Q entre eux, jamais les S.
S = U × I = √(P² + Q²) [VA] (sert à dimensionner les fils) P = U I cos φ = S cos φ [W] Q = U I sin φ = S sin φ [VAR] tan φ = Q / P ; facteur de puissance PF = P / S = cos φ
Méthode de Boucherot (n récepteurs alimentés sous la même tension U) : P_T = P₁ + P₂ + … + P_N Q_T = Q₁ + Q₂ + … + Q_N (Q > 0 bobine, Q < 0 condensateur) S_T = √(P_T² + Q_T²) = U × I_T cos φ_T = P_T / S_T
Piège : ST ≠ S₁ + S₂ + … Les puissances apparentes ne s'ajoutent pas (sauf si tous les récepteurs ont le même φ). C'est pour cela qu'on passe par PT et QT.
Exemple corrigé · exercice de la diapo 51

Le RLC série précédent (R = 200 Ω, L = 2 H, C = 10 µF) est branché en parallèle avec C₂ = 4 µF sous E = 230 V, 50 Hz. Puissances de chaque dipôle, puis bilan.

Voir la correction
|Z_RLC| = 368,9 Ω ; I_RLC = 230 / 368,9 = 0,623 A P_R = R I² = 200 × 0,623² = 77,7 W Q_R = 0 Q_L = Lω I² = 628,3 × 0,623² = 244,2 VAR Q_C = −I² / (Cω) = −318,3 × 0,623² = −123,7 VAR Q_C2 = −E² C₂ω = −230² × 4×10⁻⁶ × 314,2 = −66,5 VAR RLC seul : S_RLC = 230 × 0,623 = 143,4 VA ; cos φ_RLC = 77,7/143,4 = 0,542 ; φ_RLC = 57,2° Total : P_T = 77,7 W ; Q_T = 244,2 − 123,7 − 66,5 = 54,0 VAR S_T = √(77,7² + 54,0²) = 94,7 VA ; I_T = 94,7 / 230 = 0,412 A cos φ_T = 77,7 / 94,7 = 0,821 ; φ_T = 34,8°

IT (0,412 A) est plus petit que IRLC (0,623 A) : C₂ fournit une partie de la puissance réactive consommée par la bobine, le réseau en fournit donc moins.

Relever le facteur de puissance, appareils de mesure

diapos 52 et 53 · 30 min
L'idée. Un moteur consomme du réactif, donc il demande plus de courant que nécessaire. Un condensateur en parallèle fournit ce réactif sur place : la puissance active ne change pas, mais le courant de ligne baisse.
Rendement : η = P_U / P_A → P_A = P_U / η Condensateur pour passer de φ à φ' (P inchangée) : Q_C = −P (tan φ − tan φ') C = P (tan φ − tan φ') / (U² ω) Courant après relèvement : I' = P / (U cos φ')
Exemple corrigé · moteur asynchrone (diapo 52)

U = [230 V ; 0°], 50 Hz, Im = 52 A, PU = 8 kW, η = 85 %. On veut cos φmC = 0,8.

Voir la correction
P_Am = 8000 / 0,85 = 9412 W cos φ_m = P_Am / (U I_m) = 9412 / (230 × 52) = 0,787 ; φ_m = 38,1° Q_m = P_Am tan φ_m = 9412 × 0,784 = 7380 VAR tan φ_mC = tan(arccos 0,8) = 0,75 C = 9412 × (0,784 − 0,75) / (230² × 314,2) = 19,3 µF I_C = U C ω = 230 × 19,3×10⁻⁶ × 314,2 = 1,40 A I_mC = P_Am / (U cos φ_mC) = 9412 / (230 × 0,8) = 51,2 A

Le gain est faible ici (52 A → 51,2 A), car le facteur de puissance de départ (0,787) est déjà proche de 0,8.
