Chapitre 1 · Principes généraux et outils mathématiques

Principes généraux

Additionner deux forces : parallélogramme et trigonométrie

C = √(A² + B² − 2AB cos(c)) (loi des cosinus) A / sin(a) = B / sin(b) = C / sin(c) (loi des sinus)

Système coplanaire : composantes et notation cartésienne

Fx = F cos(θ) Fy = F sin(θ)
Fx = F (a / c) Fy = −F (b / c)
F = Fx i + Fy j
Signes. Le signe + ou − ne sert qu'au calcul. Sur un schéma, c'est la pointe de la flèche qui indique le sens, et l'intensité écrite à côté est toujours positive.

Résultante de forces coplanaires : méthode analytique

(F_R)x = ΣFx (F_R)y = ΣFy F_R = √((F_R)x² + (F_R)y²) θ = tan⁻¹ |(F_R)y / (F_R)x|

Vecteurs cartésiens en 3D

A = Ax i + Ay j + Az k A = √(Ax² + Ay² + Az²)
cos α = Ax / A cos β = Ay / A cos γ = Az / A
u_A = A / A = (Ax / A) i + (Ay / A) j + (Az / A) k = cos α i + cos β j + cos γ k cos² α + cos² β + cos² γ = 1 A = A u_A = A cos α i + A cos β j + A cos γ k
Az = A cos φ A' = A sin φ (projection dans le plan xy) Ax = A' cos θ = A sin φ cos θ Ay = A' sin θ = A sin φ sin θ A = A sin φ cos θ i + A sin φ sin θ j + A cos φ k
R = A + B = (Ax + Bx) i + (Ay + By) j + (Az + Bz) k F_R = ΣF = ΣFx i + ΣFy j + ΣFz k

Vecteur position et force dirigée le long d'une droite

r = x i + y j + z k
r = (xB − xA) i + (yB − yA) j + (zB − zA) k
Règle pratique. Coordonnées de la tête (B) moins coordonnées de la queue (A). La norme de r donne la longueur du câble, et u = r / r sa direction.
F = F u = F (r / r) F = F [ (xB − xA) i + (yB − yA) j + (zB − zA) k ] / √((xB − xA)² + (yB − yA)² + (zB − zA)²)

Produit scalaire

A · B = A B cos θ avec 0° ≤ θ ≤ 180°
A · B = Ax Bx + Ay By + Az Bz
θ = cos⁻¹( A · B / (A B) ) 0° ≤ θ ≤ 180°
A_a = A cos θ = A · u_a (composante parallèle, projection) A_a (vecteur) = A_a u_a A_⊥ = A sin θ = √(A² − A_a²) (composante perpendiculaire)

Condition d'équilibre

Le diagramme du corps libre (DCL)

F = k s s = l − l0

Systèmes de forces coplanaires (2D)

ΣFx i + ΣFy j = 0 ΣFx = 0 ΣFy = 0
Sens inconnu. Sur le DCL, on peut supposer le sens d'une force inconnue. Si le calcul donne un scalaire négatif, le sens réel est simplement opposé à celui supposé.

Chapitre 3 · Moment d'une force

Définition : moment et bras de levier

M_O = F d (en N·m ou lb·ft)

Le produit vectoriel

| i j k | A × B = | Ax Ay Az | | Bx By Bz | Composante i : i (Ay Bz − Az By) Composante j : −j (Ax Bz − Az Bx) ← attention au signe négatif ! Composante k : k (Ax By − Ay Bx) A × B = (Ay Bz − Az By) i − (Ax Bz − Az Bx) j + (Ax By − Ay Bx) k
Vérification gratuite. Le résultat est perpendiculaire à A et à B : (A × B) · A = 0 et (A × B) · B = 0. Si ce n'est pas le cas, il y a une erreur de signe.

Moment par le produit vectoriel

M_O = r × F M_O = r F sin θ (θ = angle entre r et F) d = r sin θ → M_O = F d
M_x = ry F_z − rz F_y M_y = rz F_x − rx F_z M_z = rx F_y − ry F_x
M_R = Σ (r_i × F_i) M_Rx = Σ M_xi M_Ry = Σ M_yi M_Rz = Σ M_zi

Théorème de Varignon

MO = r × (F1 + F2) = r × F1 + r × F2
M_O = F_x y − F_y x

Moment par rapport à un axe

M_a = u_a · (r × F) (un nombre, en N·m)
