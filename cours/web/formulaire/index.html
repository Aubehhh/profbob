Chapitre 1 · Bases du web et du HTML

Le web : client, serveur et LAMP

LAMP = Linux + Apache + MySQL + PHP. Back-end : le serveur envoie les bonnes informations (bases de données, architecture). Front-end : le client affiche correctement (design, interactivité). C'est le front-end qu'on fait dans ce cours.

Les balises

Imbrication. On peut ouvrir une balise à l'intérieur de n'importe quelle balise double, à condition de fermer d'abord la plus intérieure : <p><b>…</b></p>, jamais <p><b>…</p></b>. On indente le code pour qu'il reste lisible.

Chapitre 2 · Structures en HTML

Mise en page par blocs

Conclusion du cours. Une page = doctype, head, puis body. Le body est découpé en blocs, et la méthode la plus souple (div + CSS) est la meilleure.

Chapitre 3 · CSS

Le CSS et son intégration

Le débogueur du navigateur (F12, ou F8 selon le navigateur) montre la structure HTML, le CSS appliqué à chaque élément et la console d'erreurs JavaScript. C'est l'outil n°1 pour comprendre pourquoi un style ne s'applique pas.

Syntaxe, blocs, id et class, sélecteurs

nom de balise → p { … } toutes les balises p id (unique) → #test { … } l'élément qui a id="test" (symbole #) class → .reddiv { … } tous les éléments de class="reddiv" (symbole .)

Unités et propriétés principales

Couleurs : mots-clés blue, white, yellow… hexadécimal #RRGGBB (#00FF32 : rouge 00, vert FF, bleu 32) hexadécimal court #RGB (#F80 = #FF8800) rgb(0-255, 0-255, 0-255) et rgba(…, opacité de 0 à 1) autres : hsl, hsla…
Hexadécimal → décimal : chaque paire de chiffres est un nombre de 0 à 255 chiffres 0-9 puis A=10, B=11, C=12, D=13, E=14, F=15 « 3C » = 3 × 16 + 12 = 60 ; « FF » = 15 × 16 + 15 = 255

Responsive design et media queries

@media type and (contrainte) { règles CSS } type : screen, print, all… contraintes : max-width, min-width, combinées avec and

Chapitre 4 · Formulaires

La balise form : GET et POST

URL envoyée en GET : page?nom1=valeur1&nom2=valeur2 ? sépare l'adresse des données ; & sépare deux champs ; nom = attribut name du champ

Les éléments : input, label et leurs attributs

type : text, checkbox, radio, range, password, button, submit… id : identifiant (pour le CSS et pour relier le label) name : nom de la variable envoyée au serveur value : valeur par défaut (ou valeur envoyée pour checkbox et radio) <label for="X"> est relié au champ dont l'id vaut X

Terminer un formulaire : le bouton submit

Conclusion du cours. form (method + action), puis des input et un bouton. Pour exploiter les données reçues, il faut en général du PHP côté serveur.

D'après le cours « Développement et Architecture Web » de R. Gosswiller (HEI 1, JUNIA). Fiche construite automatiquement à partir des pages du site.
