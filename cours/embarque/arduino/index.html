L'IDE et la carte Arduino Uno

diapos 22 à 33 · 30 min
L'idée. On écrit le programme sur l'ordinateur dans un IDE, qui le compile puis le téléverse dans la carte. La carte exécute ensuite le programme toute seule.
  • IDE (environnement de développement intégré) : écrire le code, le compiler (le traduire pour le microcontrôleur visé), le téléverser dans la carte. Il fournit aussi le moniteur série, la gestion des cartes et des bibliothèques, la console d'erreurs.
  • Arduino IDE utilise un langage proche du C++. Arduino est open source, avec une grande communauté (arduino.cc) et beaucoup de bibliothèques.
  • Avant de téléverser : choisir le type de carte et le port de l'ordinateur.

Structure d'un programme Arduino

diapos 34 à 37 · 35 min
L'idée. Trois parties : on déclare les variables, setup() s'exécute une fois au démarrage, puis loop() se répète à l'infini.
int variable1 = 11;          // 1) déclaration des variables

void setup() {               // 2) une seule fois, au démarrage
  Serial.begin(9600);        //    ouvre le moniteur série à 9600 bauds
}

void loop() {                // 3) en boucle, sans fin
  Serial.println(variable1); //    affiche 11
  delay(1000);               //    pause de 1000 ms = 1 s
}
TypeTaille sur UnoValeurs
byte8 bits0 à 255
int16 bits−32 768 à 32 767
unsigned long32 bits0 à 4 294 967 295 (pour millis())
bool (boolean)1 octettrue / false
Stringvariabledu texte
Coquille du cours (diapo 34). Un booléen « sur 1 bit » : en mémoire, un bool Arduino occupe 1 octet (8 bits), même s'il ne sert qu'à stocker vrai ou faux.
  • Couleurs de l'IDE : fonctions connues en orange, constantes (HIGH, OUTPUT…) en bleu, commentaires en gris (// commentaire).
  • Chaque instruction se termine par un point-virgule.
Piège. Sans delay(), loop() tourne des milliers de fois par seconde : le « 11 » s'affiche en continu, très vite. Avec delay(1000), il s'affiche une fois par seconde.

Contrôler une sortie : le programme Blink

diapos 38 à 41 · 30 min
L'idée. On déclare le port en sortie avec pinMode, puis on l'allume et l'éteint avec digitalWrite. Il faut un délai après chaque changement, sinon le clignotement est trop rapide pour être vu.
int Ledpin = 11;

void setup() {
  pinMode(Ledpin, OUTPUT);       // le port 11 devient une sortie
}

void loop() {
  digitalWrite(Ledpin, HIGH);    // 5 V : LED allumée
  delay(1000);
  digitalWrite(Ledpin, LOW);     // 0 V : LED éteinte
  delay(1000);
}
pinMode(port, OUTPUT ou INPUT) choisir le sens du port (dans setup) digitalWrite(port, HIGH ou LOW) sortie à 5 V ou 0 V delay(ms) pause en millisecondes Période du clignotement = durée allumée + durée éteinte ; fréquence = 1 / période

L'IDE propose le même programme dans ses exemples (Blink), avec LED_BUILTIN, la LED soudée sur la carte.

Exemple corrigé · TD 1 : feu tricolore

Allumer la LED verte 3 s, puis l'orange 1 s, puis la rouge 5 s, avec une fonction allumer(LED, temps).

Voir la correction
int LED_ROUGE = 8;
int LED_ORANGE = 9;
int LED_VERTE = 2;

void allumer(int LED, int temps) {
  digitalWrite(LED, HIGH);
  delay(temps);
  digitalWrite(LED, LOW);
}

void setup() {
  pinMode(LED_ROUGE, OUTPUT);
  pinMode(LED_ORANGE, OUTPUT);
  pinMode(LED_VERTE, OUTPUT);
}

void loop() {
  allumer(LED_VERTE, 3000);
  allumer(LED_ORANGE, 1000);
  allumer(LED_ROUGE, 5000);
}

Un cycle complet dure 3 + 1 + 5 = 9 s. Les erreurs fréquentes dans ce TD :

  • oublier les points-virgules ;
  • remettre HIGH au lieu de LOW pour éteindre ;
  • oublier les types des paramètres (int LED, int temps) ;
  • oublier le pinMode de la LED verte ;
  • déclarer la fonction int alors qu'elle ne renvoie rien : il faut void.

Une LED reste allumée 500 ms et éteinte 500 ms. Combien de fois clignote-t-elle par minute ?

Période = 500 + 500 = 1000 ms, donc 60 clignotements en 60 s.

Moniteur série et écran LCD (TD 2)

TD 2 · 25 min
L'idée. Pour voir ce que fait le programme, on affiche des valeurs sur le moniteur série de l'ordinateur, ou sur l'écran LCD de 16 colonnes et 2 lignes fourni avec la carte.
Serial.begin(9600) ouvrir la liaison série (dans setup) Serial.print(x) afficher sans aller à la ligne Serial.println(x) afficher puis aller à la ligne #include <LiquidCrystal.h> bibliothèque de l'écran LCD lcd.begin(16, 2) écran de 16 colonnes, 2 lignes lcd.setCursor(col, lig) placer le curseur (col de 0 à 15, lig 0 ou 1) lcd.print("texte") ; lcd.clear()
Exemple corrigé · TD 2, exercices 1 et 2
Voir la correction
int compteur = 0;

void setup() {
  Serial.begin(9600);
  Serial.println("Hello Computer");
}

void loop() {
  compteur = compteur + 1;
  delay(1000);
  Serial.print("*");          // une étoile par seconde
  if (compteur == 10) {       // toutes les 10 étoiles…
    compteur = 0;
    Serial.println("");       // …on passe à la ligne
  }
}
#include <LiquidCrystal.h>
LiquidCrystal lcd(15, 14, 4, 5, 6, 7);

void setup() {
  lcd.begin(16, 2);
  lcd.clear();
  lcd.setCursor(0, 0);  lcd.print("Hello");   // en haut à gauche
  lcd.setCursor(11, 1); lcd.print("World");   // en bas à droite : 11 + 5 lettres = 16 colonnes
}

Méthode
