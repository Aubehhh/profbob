Chapitre 1 · Concepts et définitions d'introduction

Variables d'état, état et transformation

Test rapide. Coupe le système en deux moitiés : ce qui est divisé par 2 est extensif (m, V, U), ce qui ne change pas est intensif (p, T, ρ, v).

Unités, masse volumique et volume spécifique

F = m a (Eq. 1.1) SI : 1 N = (1 kg)(1 m/s²) = 1 kg·m/s² (Eq. 1.2) ρ = lim (m / V) quand V → V' (Eq. 1.3) en kg/m³ v = 1/ρ en m³/kg

La pression

p = lim (F_normale / A) quand A → A' (Eq. 1.4) 1 Pa = 1 N/m² 1 kPa = 10³ N/m² 1 bar = 10⁵ N/m² 1 MPa = 10⁶ N/m²
p(relative) = p(absolue) − p_atm(absolue) (Eq. 1.5) si p > p_atm p(vide) = p_atm(absolue) − p(absolue) (Eq. 1.6) si p < p_atm
Colonne de liquide de hauteur L : Δp = ρ g L Piston de masse m et d'aire A à l'équilibre : p A = p_atm A + m g → p = p_atm + m g / A

La température

T(°C) = T(K) − 273,15 (Eq. 1.7)

Chapitre 2 · L'énergie et le premier principe

L'énergie d'un système et ses variations

ΔE_c = E_c2 − E_c1 = ½ m (V_2² − V_1²) (Eq. 2.5) V = vitesse ΔE_p = E_p2 − E_p1 = m g (z_2 − z_1) (Eq. 2.10) z = altitude Énergie interne : U (massique u, molaire U_m), lue dans les tables E_2 − E_1 = (U_2 − U_1) + (E_c2 − E_c1) + (E_p2 − E_p1) (Eq. 2.27a) ΔE = ΔU + ΔE_c + ΔE_p (Eq. 2.27b)

Travail et chaleur : les conventions de signe

W > 0 : travail fourni par le système W < 0 : travail fourni sur le système Q > 0 : chaleur reçue par le système Q < 0 : chaleur cédée par le système

Le bilan d'énergie du système fermé

E_2 − E_1 = Q − W (Eq. 2.35a) ΔE_c + ΔE_p + ΔU = Q − W (Eq. 2.35b) Forme temporelle (bilan de puissances) : dE/dt = P_th − P_méca (Eq. 2.37)

Travail de détente et de compression

F = p × A W = ∫ F dx = ∫ p A dx W = ∫ p dV (de V_1 à V_2) (Eq. 2.17)
p Vⁿ = constante n = 1 : W = (constante) ln(V_2 / V_1) avec constante = p_1 V_1 = p_2 V_2
n = 0 (p constante) : W = p (V_2 − V_1) n ≠ 1 : W = (p_2 V_2 − p_1 V_1) / (1 − n) avec p_2 = p_1 (V_1 / V_2)ⁿ

Les modes de transfert de chaleur

Q̇_x = −κ A dT/dx (Eq. 2.31) Mur plan en régime permanent : dT/dx = (T_2 − T_1)/L (< 0) → Q̇_x = −κ A (T_2 − T_1)/L
Φ = ε σ A (T_b⁴ − T_s⁴) (Eq. 2.33) σ = 5,67×10⁻⁸ W/(m²·K⁴)
Φ_conv = h A (T_b − T_f) (Eq. 2.34)

Les cycles thermodynamiques

ΔE_cycle = Q_cycle − W_cycle = 0 (Eq. 2.39)
Comment ne pas se tromper. La performance = ce qu'on veut ÷ ce qu'on paie. Moteur : on veut W, on paie Qin. Frigo : on veut Qin (le froid), on paie W. Pompe à chaleur : on veut Qout (le chaud), on paie W. Donc γ = β + 1 > 1.

Chapitre 3 · Évaluation des propriétés thermodynamiques

Phase, substance pure et principe d'état

Principe d'état. Pour un système compressible simple, deux propriétés intensives indépendantes suffisent à fixer toutes les autres. Les couples (T, v) et (p, v) sont souvent pratiques. Attention : dans un mélange liquide-vapeur, p et T ne sont pas indépendantes.

Le changement de phase et le titre en vapeur

x = m_vapeur / m_totale 0 ≤ x ≤ 1 liquide saturé : x = 0 vapeur saturée : x = 1

Lire les tables et interpoler

h = u + p v (Eq. 3.4)

Propriétés d'un mélange liquide-vapeur

V = V_liq + V_vap → v = V/m = (1 − x) v_f + x v_g v = (1 − x) v_f + x v_g = v_f + x (v_g − v_f) (Eq. 3.2) u = (1 − x) u_f + x u_g = u_f + x (u_g − u_f) (Eq. 3.6) h = (1 − x) h_f + x h_g = h_f + x (h_g − h_f) (Eq. 3.7)

Chaleurs massiques, liquides et incompressibles

c_v = (∂u/∂T)_v c_p = (∂h/∂T)_p k = c_p / c_v (Eq. 3.8, 3.9, 3.10)
v(T, p) ≈ v_f(T) u(T, p) ≈ u_f(T) (Eq. 3.11, 3.12) h(T, p) ≈ h_f(T) + v_f(T) [p − p_sat(T)] (Eq. 3.13) h(T, p) ≈ h_f(T) si le terme entre crochets est petit (Eq. 3.14)
u_2 − u_1 = c (T_2 − T_1) (Eq. 3.20a) h_2 − h_1 = c (T_2 − T_1) + v (p_2 − p_1) (Eq. 3.20b)

Le modèle du gaz parfait

p V = n R T (Eq. 3.35) R = 8,314 J/(mol·K) p V = m r T (Eq. 3.33) n = m/M, r = R/M p v = r T (Eq. 3.32) v = V/m
u = u(T) (Eq. 3.36) h = u + p v = u(T) + r T (Eq. 3.37) c_v(T) = du/dT c_p(T) = dh/dT (Eq. 3.38, 3.41) Chaleurs massiques constantes : u(T_2) − u(T_1) = c_v [T_2 − T_1] (Eq. 3.50) h(T_2) − h(T_1) = c_p [T_2 − T_1] (Eq. 3.51)
p Vⁿ = constante (Eq. 3.52) n = 0 : isobare n = ±∞ : isochore n = 1 (gaz parfait) : isotherme

Chapitre 4 · Analyse par volume de contrôle fondée sur l'énergie

Bilan des débits massiques

dm_vc/dt = q_m,e − q_m,s (Eq. 4.1) dm_vc/dt = Σ_e q_m,e − Σ_s q_m,s (Eq. 4.2) plusieurs entrées / sorties Débit massique (écoulement 1D) : q_m = A V / v (Eq. 4.4b) A : section, V : vitesse moyenne, v : volume massique Régime permanent : Σ_e q_m,e = Σ_s q_m,s (Eq. 4.6)

Bilan de puissance pour un volume de contrôle

dE_vc/dt = P_th − P_méca + q_m,e (u_e + V_e²/2 + g z_e) − q_m,s (u_s + V_s²/2 + g z_s) (Eq. 4.9) Puissance mécanique : P_méca = P_méca,vc + q_m,s (p_s v_s) − q_m,e (p_e v_e) (Eq. 4.12) P_méca,vc : arbres tournants, déplacement de frontière, effets électriques q_m (p v) : travail d'écoulement en sortie et en entrée Avec h = u + p v : dE_vc/dt = P_th,vc − P_méca,vc + Σ_e q_m,e (h_e + V_e²/2 + g z_e) − Σ_s q_m,s (h_s + V_s²/2 + g z_s) (Eq. 4.15)
0 = P_th,vc − P_méca,vc + q_m [ (h_e − h_s) + (V_e² − V_s²)/2 + g (z_e − z_s) ] (Eq. 4.20a) En divisant par le débit : 0 = Q_vc − W_vc + (h_e − h_s) + (V_e² − V_s²)/2 + g (z_e − z_s) (Eq. 4.20b)

Échangeurs de chaleur, détendeurs et intégration

0 = Σ_e q_m,e h_e − Σ_s q_m,s h_s
h_e = h_s (Eq. 4.22)

Chapitre 5 · Le second principe de la thermodynamique

Les énoncés du second principe

Réservoir thermique. Un système qui garde une température constante malgré les échanges de chaleur : l'atmosphère, un lac, l'océan, un gros bloc de cuivre.

Kelvin-Planck en équation et rendement entre deux réservoirs

Un seul réservoir : W_cycle ≤ 0 (Eq. 5.3) < 0 : des irréversibilités internes sont présentes = 0 : aucune irréversibilité interne
W_cycle = Q_C − Q_F η = W_cycle / Q_C = 1 − Q_F / Q_C (Eq. 5.4)
Pourquoi η < 1. Si QF valait 0, le moteur fonctionnerait avec un seul réservoir et fournirait du travail : Kelvin-Planck l'interdit. Il faut donc toujours rejeter une partie de la chaleur, et η < 100 %.
